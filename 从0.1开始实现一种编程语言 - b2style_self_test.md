# 从0.1开始实现一种编程语言 - b2style_self_test

之前为语言的新功能增加测试的时候，都要先写一段期待能运行的代码，把这段代码编译进.net的包中（通过base64编码的字符串），写一段[http://vb.net](http://vb.net)的代码编译这段代码（从base64编码的字符串反转回字节/原始的字符串），用simulator执行编译的代码，比较输出和预期是否一样。虽然这些步骤一个也不能少，不过后面[http://vb.net](http://vb.net)的代码基本上来说是重复的。所以就考虑一下怎样可以简化这个过程，当然有些东西还是必须的，比如把需要测试的代码编译进.net的包中，我不太想测试内容依赖于我把文件放在哪里。优化后的流程大概是这样：

- 写若干段期待能运行的代码，这段代码中包含了一些断言。
- 把这段代码编译进.net的包中。
- 用[http://vb.net](http://vb.net)实现一个通用的编译、运行、测试的过程，其中断言的内容用来测试。

这样再增加测试代码的时候也只需要写一个带断言的代码即可，第二步是运行个命令，第三步和测试代码本身无关的。

因为运行测试需要遍历所有的测试文件，之前的genall ([service/tests/compiler/b2style/codegen/run.cmd](https://github.com/Hzj-jie/osi.net/blob/master/service/tests/compiler/b2style/codegen/run.cmd))的模式就不能用了，这样每个文件是独立的字节串。

```bat
setlocal
path %PATH%;..\..\..\..\resource\gen;
genall --pattern=*.txt _b2style_test_data > b2style_test_data.vb
move /Y b2style_test_data.vb ..\
endlocal

```

虽然也可以用反射，不过何必呢？不如用[service/resource/tar](https://github.com/Hzj-jie/osi.net/tree/master/service/resource/tar)。

这个tar和posix的tar很像，就是把若干个文件打包成一个，其内置还有压缩等功能。本来是用来把大量小文件存在一起节省空间。在此处的用法也略有差别，打包之后的数据还是会用base64转成字符串保存在代码中，所以用到一个[in_mem_fs](https://github.com/Hzj-jie/osi.net/blob/master/service/resource/tar/fs.vb#L194)来取代之前的文件操作的[default_fs](https://github.com/Hzj-jie/osi.net/blob/master/service/resource/tar/fs.vb#L54)。不过这些都是tar实现的细节，这里就不多做说明，简单说来就是实现了[tar/gen](https://github.com/Hzj-jie/osi.net/blob/master/service/resource/tar/gen.vb)的功能。

```text
Public Shared Function read() As MemoryStream
    Dim o As New MemoryStream()
    assert(writer.in_mem(size Or 10 * 1024 * 1024,
                         New selector() With {.pattern = pattern Or "*"},
                         o).dump())
    Return o
End Function

Public Shared Function reader_of(ByVal input As MemoryStream) As reader
    Return reader.in_mem(input)
End Function

Public Shared Sub dump(ByVal input As MemoryStream, ByVal root As String)
    reader_of(input).foreach(Sub(ByVal file As String, ByVal m As MemoryStream)
                                 assert(Not file Is Nothing)
                                 assert(Not m Is Nothing)
                                 Try
                                     Directory.GetParent(Path.Combine(root, file)).Create()
                                 Catch ex As Exception
                                     assert(False, ex)
                                 End Try
                                 IO.File.WriteAllBytes(Path.Combine(root, file), m.bytes())
                             End Sub)
End Sub

```

其中包含两组api，`read`用以将文件写入内存，为之后的base64编码准备；`dump`和`reader_of`把一段内存读出，前者释放到特定的文件夹，后者由`tar.reader`完成其它类型的操作，比如直接把字符串读出来。

 这也正好符合两个不同的需求，前者可以把bstyle和[b2style的lib](https://github.com/Hzj-jie/osi.net/tree/master/service/compiler/b2style/lib)直接打包，运行时释放；后者可以遍历每个测试文件进行测试。

```vb.net
<test>
Private Shared Sub run()
    Dim a As New vector(Of Action)()
    tar.gen.reader_of(b2style_self_test_cases.data).foreach(
        Sub(ByVal name As String,
            ByVal enc_precision As Double,
            ByVal content As StreamReader)
            Dim text As String = content.ReadToEnd()
            a.emplace_back(Sub()
                               execute(name, text)
                           End Sub)
        End Sub)
    assertions.of(a).not_empty()
    concurrency_runner.execute(+a)
End Sub

```

下面得在b2style的代码中加点东西，现在的实现还很简单，只用`stdout`来标记，比如`b2style::testing:assert_true(true)`写出`Success: no extra information`，最后用`b2style::testing::finished()`标记测试结束。在vb.net的代码中检测是不是所有的输出都是符合预期的。

[osi.net/service/compiler/b2style/lib/testing at master · Hzj-jie/osi.net](https://github.com/Hzj-jie/osi.net/tree/master/service/compiler/b2style/lib/testing)

```cpp
void assert_true(bool v, string msg) {
  _assertion_count++;
  string prefix;
  if (v) {
    prefix = "Success: ";
  } else {
    prefix = "Failure: ";
  }
  ::b2style::std_out(prefix);
  ::b2style::std_out(msg);
  ::b2style::std_out("\n");
}

void finished() {
  ::b2style::std_out("Total assertions: ");
  ::b2style::std_out(_assertion_count);
  ::b2style::std_out("\n");
}

```

当然也可以增加一个`loaded_method`，用来处理更加复杂的断言，不过暂时感觉用不到。
