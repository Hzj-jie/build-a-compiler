# 从0.1开始实现一个编程语言 - 更准确的检测函数调用

[Zijie He：从0.1开始实现一种编程语言 - 优化一下，从编译结果中删除不需要的函数](https://zhuanlan.zhihu.com/p/443777931)中提到bstyle和b2style编译器都可以从生成的代码中删除不被引用的函数，以减少代码的体积和编译的时间。

当时的实现过于简单，甚至没有考虑一些边界情况，从而导致运行速度慢并且还会在特定情况下栈溢出，比如这个例子。[service/tests/compiler/b2style/self-test/call-func-in-param.txt](https://github.com/Hzj-jie/osi.net/blob/master/service/tests/compiler/b2style/self-test/call-func-in-param.txt)，这个名字不太好。

```cpp
#include <b2style.h>
#include <testing.h>

void f(int x) {}

void g() {
  f(1);
}

void f() {
  g();
}

void main() {
  f();
  b2style::testing::finished();
}

```

看起来是个很简单的代码，不过介于b2style并不处理函数重载，在处理`f`这个函数的时候就会导致了`f->g->f`的死循环，从而导致栈溢出。当时的实现是递归实现的深度优先搜索。

```cpp
assert(Not f.null_or_whitespace())
If f.Equals(main_name) Then
    Return True
End If
Dim it As unordered_map(Of String, Boolean).iterator = tm.find(f)
If it <> tm.end() Then
    Return (+it).second
End If
Dim r As Boolean = False
Dim it2 As unordered_map(Of String, vector(Of String)).iterator = m.find(f)
If it2 <> m.end() Then
    Dim v As vector(Of String) = (+it2).second
    assert(Not v.null_or_empty())
    For i As UInt32 = 0 To v.size() - uint32_1
        If can_reach_root(v(i)) Then
            r = True
            Exit For
        End If
    Next
End If
tm(f) = r
Return r

```

 简单点的想法就是转换成不用递归的实现。深度还是广度应该对速度影响有限，不过广度优先搜索更直观一些。

## 反向搜索

当然最优的做法应该是反过来由main函数开始，而不是到main函数结束。不过这样需要在编译过程中增加一个特定的步骤，以便在代码生成后检查可以被main函数直接或间接引用的函数列表。这与现在的编译器实现方法并不完全一致，不过可以通过增加一个suffix来完成计算。suffix本身的功能是在编译的代码后添加一些内容，这个操作在编译和输出编译结果之间，正好符合要求。当然这只是实现的细节。

实现上仍然是广度优先搜索，只是从`main`函数开始。

```vb.net
        Private Sub calculate()
            assert(tm Is Nothing)
            tm = New unordered_set(Of String)()
            Dim q As New queue(Of String)()
            q.emplace(main_name)
            assert(tm.emplace(main_name).second())
            Dim f As String = Nothing
            While q.pop(f)
                Dim fs As vector(Of String) = Nothing
                If Not m.find(f, fs) Then
                    Continue While
                End If
                assert(Not fs Is Nothing)
                fs.stream().
                   filter(Function(ByVal other As String) As Boolean
                              ' filter requires stateless operations.
                              Return tm.find(other) = tm.end()
                          End Function).
                   foreach(Sub(ByVal other As String)
                               q.emplace(other)
                               assert(tm.emplace(other).second())
                           End Sub)
            End While
        End Sub 

```

这个函数则由名为`call_hierarchy.calculator`的suffix调用。

```vb.net
        Public NotInheritable Class calculator
            Implements statement(Of WRITER)

            Private Shared ReadOnly instance As New calculator()

            Private Sub New()
            End Sub

            Public Shared Sub register(ByVal p As statements(Of WRITER))
                assert(Not p Is Nothing)
                p.register(instance)
            End Sub

            Public Sub export(ByVal o As WRITER) Implements statement(Of WRITER).export
                current().call_hierarchy().calculate()
            End Sub
        End Class 

```

完成计算后，`tm`中则为每个函数是否在运行时有意义。
