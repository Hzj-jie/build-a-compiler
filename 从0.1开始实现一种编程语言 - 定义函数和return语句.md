# 从0.1开始实现一种编程语言 - 定义函数和return语句

回忆一下logic语言在实现函数和return语句的时候有点偷懒，return语句总需要提供函数名：

```text
callee copy-one-byte1 type0 ( source type* pos uint len uint ) {
    define char type*
    cut_slice char source pos len
    append target1 char
    return copy-one-byte1 *
}

```

这是个没什么意义的决定，不过既然实现已经如此，也没有什么很必要的意义去修改。相反在bstyle语言中再实现一个不需要函数名的return语句。

和之前提到的read_scoped一样，先实现一个write_scoped。和read_scoped反过来，write_scoped在完成写入时弹栈。亦即在写入时返回一个IDisposable，使用.net的特性实现一个安全的弹栈。[service/compiler/logic/logic_gen/scoped/write_scoped.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/logic/logic_gen/scoped/write_scoped.vb)

```vb.net
Public NotInheritable Class ref
    Implements IDisposable

    Private ReadOnly r As write_scoped(Of T)
    Private ReadOnly v As T

    Public Sub New(ByVal r As write_scoped(Of T))
        assert(Not r Is Nothing)
        assert(Not r.s.empty())
        Me.r = r
        Me.v = r.s.back()
    End Sub

    Public Sub Dispose() Implements IDisposable.Dispose
        r.s.pop()
    End Sub

    Public Shared Operator +(ByVal this As ref) As T
        assert(Not this Is Nothing)
        Return this.v
    End Operator
End Class

Public Function push(ByVal v As T) As ref
    s.emplace(v)
    Return New ref(Me)
End Function

Public Function current() As T
    assert(Not s.empty())
    Return s.back()
End Function

```

function的实现使用write_scoped来记录当前的函数定义。虽然在编译的时候bstyle还不支持类似函数的嵌套在内的行为，所以只需要一个函数定义即可。不过介于write_scoped的实现简化了很多小问题，也为以后为bstyle语言增加功能方便，所以就简单的使用write_scoped。

[service/compiler/bstyle/logic/nodes/function.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/bstyle/logic/nodes/function.vb)

function实现一个ref用于记录当前的正在编译的函数：

```vb.net
Public NotInheritable Class ref
    Private ReadOnly ta As type_alias
    Private ReadOnly params As vector(Of pair(Of String, String))
    Private ReadOnly n As typed_node

    Public Sub New(ByVal ta As type_alias,
                   ByVal params As vector(Of pair(Of String, String)),
                   ByVal n As typed_node)
        assert(Not ta Is Nothing)
        assert(Not params Is Nothing)
        assert(Not n Is Nothing)
        assert(n.child_count() = 5 OrElse n.child_count() = 6)
        Me.ta = ta
        Me.params = params
        Me.n = n
    End Sub

    Public Function allow_return_value() As Boolean
        Return Not strsame(n.child(0).word().str(), types.void)
    End Function

    Public Function name() As String
        Return function_name.of_function(ta, n.child(1).word().str(), params)
    End Function
End Class

```

里面还有些type_alias和function_name的实现细节之后再说。除此以外ref记录了当前函数的名称，并提供一些比如是否允许返回值的函数。

当编译一个函数的内容的时候，将这个定义压栈，这样函数内容在被编译的时候就可以取得函数的细节了。

```vb.net
function_name.of_callee(ta,
                        n.child(1).word().str(),
                        n.child(0).word().str(),
                        +params,
                        Function() As Boolean
                            Using s.push(New ref(ta, +params, n))
                                Dim gi As UInt32 = 0
                                gi = CUInt(If(has_paramlist, 5, 4))
                                Return l.of(n.child(gi)).build(o)
                            End Using
                        End Function).to(o)

```

在return语句中的使用：[service/compiler/bstyle/logic/nodes/return_clause.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/bstyle/logic/nodes/return_clause.vb)

```vb.net
c = code_gen_of(Of [function])().target()
If c.allow_return_value() Then
    If n.child_count() <> 2 Then
        raise_error(error_type.user, "Expect return value ", n.child().trace_back_str())
        Return False
    End If
Else
    If n.child_count() <> 1 Then
        raise_error(error_type.user, "Unexpected return value ", n.child(1).trace_back_str())
        Return False
    End If
End If
If n.child_count() = 2 Then
    If Not l.of(n.child(1)).build(o) Then
        Return False
    End If
    Using r As read_scoped(Of String).ref = code_gen_of(Of value)().read_target()
        builders.of_return(c.name(), +r).to(o)
    End Using
Else
    builders.of_return(c.name()).to(o)
End If

```

而其中的params由paramlist实现，paramlist和param也都使用read_scoped记录当前的参数列表和参数。同样，虽然paramlist和param都不支持递归，用read_scoped可以简化实现。[service/compiler/bstyle/logic/nodes/paramlist.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/bstyle/logic/nodes/paramlist.vb)
