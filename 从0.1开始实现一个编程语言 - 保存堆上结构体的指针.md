# 从0.1开始实现一个编程语言 - 保存堆上结构体的指针

前文提到[Zijie He：实现一个编程语言 - 保存堆空间的指针](https://zhuanlan.zhihu.com/p/476306636)，不过当时实现的只能保存基础类型。回忆一下结构体在bstyle中的实现，因为primitive处理器每个数据都是不定长的，这是为了允许无精度限制的计算（[计算π的值 - 无精度限制的计算](https://www.zhihu.com/column/c_1216677226609082368)），但带来的问题是传统的整块内存的指针的结构体不能被primitive处理器处理。所以结构体是展开成若干个基础类型，而`.`只是标记每个结构体的变量的方式，本身并没有太多的语法上的意义。这是简单的做法，不过在处理堆上的数据的时候也会存在类似的问题。比如，

```cpp
struct S { int x; string y; }
void main() {
  S s[10];
}

```

其实是展开成了

```cpp
int s.x[10];
string s.y[10];

```

这两个堆空间的生存期是一样的，所以保存堆空间的指针时也需要同时考虑结构体的情况。

注意到在执行`S s[10]`语句的时候，bstyle会自动展开`S`的定义，同样的道理在执行前文说到的`logic "dealloc_heap x";`和 `logic "undefine x";`的时候也需要同时展开结构体的定义。

这里有两个做法，一是提供类似`reinterpret_cast`的伪装成函数的编译器指令，自然一个是`dealloc`，一个是`undefine`；另一种是介于这两个功能只在处理堆空间的时候用到，也可以为每个结构体生成特定的`T alloc_heap(int size);`函数。

后一种做法在bstyle语言上有明显的问题，一来还是需要标记`S s[10];`是不是要分配不会自动释放的堆空间；二来要不然处理`int x[10];`和`S s[10];`用不同的方式，要不然就得为所有基础类型都添加上`int alloc_heap(int size);`函数，但是bstyle并不知道所有的基础类型，logic语言可以随意添加基础类型。

同时和`S s[10];`类似，提供两个类似函数的编译器指令也是配对的。所以需要实现的语法是下面这样的。

```cpp
struct S { int x; string y; }

void main() {
  S s[10];
  S ptr = s;
  undefine(s);
  dealloc(ptr);
}

```

### 1、语法和词法

虽然很无聊，也说了很多次了，不过还是得说明一下。

词法上增加`kw-undefine`和`kw-dealloc`两个关键字。 

```text
  kw-delegate delegate
+ kw-undefine undefine
+ kw-dealloc dealloc

  single-line-comment //[*|\n]*

```

语法上增加`undefine`和`dealloc`两个语句。

```text
+ # Function-like instructions.
  reinterpret-cast kw-reinterpret-cast start-bracket variable-name comma type-name end-bracket
+ undefine kw-undefine start-bracket variable-name end-bracket
+ dealloc kw-dealloc start-bracket variable-name end-bracket

  root-type-with-semi-colon [value-definition, heap-declaration, value-declaration, logic, typedef, delegate]? semi-colon
  base-root-type [root-type-with-semi-colon, function, include, define, ifndef-wrapped, struct]
- base-sentence-with-semi-colon [..., delegate]? semi-colon
+ base-sentence-with-semi-colon [..., delegate, undefine, dealloc]? semi-colon 

```

这两个语句的输入和`reinterpret_cast`一样，只能是变量名`variable-name`。

### 2、bstyle的logic/nodes和b2style的rewriter/nodes

b2style中什么也不做，直接转到bstyle上。（[service/compiler/b2style/b2style.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b2style/b2style.vb)）


bstyle则有类似`reinterpret_cast`的两个实现`undefine`和`dealloc`。（[service/compiler/bstyle/bstyle.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/bstyle/bstyle.vb)）

```vb.net
   Return New code_gens_registrar(Of logic_writer)().
                 ' ...
+                with(undefine.instance).
+                with(dealloc.instance).

```

[service/compiler/bstyle/logic/nodes/undefine.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/bstyle/logic/nodes/undefine.vb)

```vb.net
Option Explicit On
Option Infer Off
Option Strict On

Imports osi.root.connector
Imports osi.service.automata
Imports osi.service.compiler.logic

Partial Public NotInheritable Class bstyle
    Private NotInheritable Class undefine
        Implements code_gen(Of logic_writer)

        Public Shared ReadOnly instance As New undefine()

        Private Sub New()
        End Sub

        Public Function build(ByVal n As typed_node,
                              ByVal o As logic_writer) As Boolean Implements code_gen(Of logic_writer).build
            assert(Not n Is Nothing)
            assert(Not o Is Nothing)
            assert(n.child_count() = 4)
            Dim name As String = n.child(2).input_without_ignored()
            Return struct.undefine(name, o) OrElse
                   builders.of_undefine(name).to(o)
        End Function
    End Class
End Class

```

[service/compiler/bstyle/logic/nodes/dealloc.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/bstyle/logic/nodes/dealloc.vb)

```vb.net
Option Explicit On
Option Infer Off
Option Strict On

Imports osi.root.connector
Imports osi.service.automata
Imports osi.service.compiler.logic

Partial Public NotInheritable Class bstyle
    Private NotInheritable Class dealloc
        Implements code_gen(Of logic_writer)

        Public Shared ReadOnly instance As New dealloc()

        Private Sub New()
        End Sub

        Public Function build(ByVal n As typed_node,
                              ByVal o As logic_writer) As Boolean Implements code_gen(Of logic_writer).build
            assert(Not n Is Nothing)
            assert(Not o Is Nothing)
            assert(n.child_count() = 4)
            Dim name As String = n.child(2).input_without_ignored()
            Return struct.dealloc_from_heap(name, o) OrElse
                   builders.of_dealloc_heap(name).to(o)
        End Function
    End Class
End Class

```

两段代码基本上一模一样，就是先尝试结构体的处理方法，不行就是基础类型的处理方式。所以关键的代码都在`struct`中。

### 3、struct.undefine和struct.dealloc

不过其实这两个函数也没有什么复杂的，不过就是把结构体的所有基础类型列出来，依次调用logic语言的`dealloc_heap`或者`undefine`指令即可。

```vb.net
Public Shared Function dealloc_from_heap(ByVal name As String, ByVal o As logic_writer) As Boolean
    assert(Not o Is Nothing)
    Dim v As struct_def = Nothing
    If Not scope.current().structs().resolve(name, v) Then
        Return False
    End If
    assert(Not v Is Nothing)
    Return v.for_each_primitive(Function(ByVal m As builders.parameter) As Boolean
                                    assert(Not m Is Nothing)
                                    Return builders.of_dealloc_heap(m.name).to(o)
                                End Function)
End Function

Public Shared Function undefine(ByVal name As String, ByVal o As logic_writer) As Boolean
    assert(Not o Is Nothing)
    Dim v As struct_def = Nothing
    If Not scope.current().structs().resolve(name, v) Then
        Return False
    End If
    assert(Not v Is Nothing)
    Return v.for_each_primitive(Function(ByVal m As builders.parameter) As Boolean
                                    assert(Not m Is Nothing)
                                    Return builders.of_undefine(m.name).to(o)
                                End Function)
End Function 

```

### 4、来点测试

[service/tests/compiler/b2style/self-test/heap.txt](https://github.com/Hzj-jie/osi.net/blob/master/service/tests/compiler/b2style/self-test/heap.txt)测试这两个指令。

```cpp
#include <b2style.h>
#include <testing.h>
#include <b2style/stdio.h>

struct S {
  int x;
  string y;
};

void main() {
  S s;
  {
    S x[10];
    s = x;
    undefine(x);
  }
  for (int i = 0; i < 10; i++) {
    s[i].x = i + 1;
    s[i].y = b2style::int_to_str(i + 2);
  }
  for (int i = 0; i < 10; i++) {
    b2style::testing::assert_equal<int>(s[i].x, i + 1);
    b2style::testing::assert_equal<string>(s[i].y, b2style::int_to_str(i + 2));
  }
  dealloc(s);
  b2style::testing::finished();
}

```

这也和之前提到的`vector`的实现方式非常接近，用一个普通变量指向一个堆空间。

### 5、b2style::heap_ptr<T>

注意到`undefine`和`dealloc`使用起来相当危险，要不然会重复释放，要不然就是忘了释放，所以把这个功能封装起来会相对安全一些。这就是[service/compiler/b2style/lib/b2style/heap_ptr.h](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b2style/lib/b2style/heap_ptr.h)。

```cpp
#ifndef B2STYLE_LIB_B2STYLE_HEAP_PTR_H
#define B2STYLE_LIB_B2STYLE_HEAP_PTR_H

#include <b2style/types.h>
#include <assert.h>

namespace b2style {

// Type T is required to use the dealloc instruction.
template <T>
class heap_ptr {
  T _a;
  int _s;

  int size() {
    return this._s;
  }

  bool empty() {
    return this.size() == 0;
  }

  void construct() {
    this._s = 0;
  }

  void destruct() {
    if (this.empty()) return;
    dealloc(this._a);
    this.construct();
  }

  void alloc(int size) {
    this.destruct();
    ::assert(size > 0);
    T x[size];
    this._a = x;
    this._s = size;
    undefine(x);
  }

  void construct(int size) {
    this.construct();
    this.alloc(size);
  }

  T get(int index) {
    ::assert(index >= 0);
    ::assert(index < this.size());
    return this._a[index];
  }

  void set(int index, T v) {
    ::assert(index >= 0);
    ::assert(index < this.size());
    this._a[index] = v;
  }

  void release() {
    this.construct();
  }
};

}  // namespace b2style

#endif  // B2STYLE_LIB_B2STYLE_HEAP_PTR_H

```

基本上是些实现的细节，并没有什么太特别的地方。

### 6、std/vector和b2style/ref.h都可以用b2style::heap_ptr<T>

[service/compiler/b2style/lib/b2style/ref.h](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b2style/lib/b2style/ref.h)，这是一个堆上唯一的变量的指针。

```cpp
#ifndef B2STYLE_LIB_B2STYLE_REF_H
#define B2STYLE_LIB_B2STYLE_REF_H

#include <b2style.h>
#include <b2style/heap_ptr.h>
#include <assert.h>

namespace b2style {

template <T>
class ref {
  heap_ptr<T> _a;

  void destruct() {
    this._a.destruct();
  }

  bool empty() {
    return this._a.empty();
  }

  void set(T v) {
    if (this.empty()) this._a.alloc(1);
    this._a.set(0, v);
  }

  void alloc() {
    T v;
    this.set(v);
  }

  T get() {
    ::assert(!this.empty());
    return this._a.get(0);
  }

  T release() {
    T r = this.get();
	this.destruct();
    return r;
  }

  void construct() {}

  void construct(T v) {
    this.construct();
    this.set(v);
  }

  void construct(ref<T>& other) {
    this.construct(other.release());
  }
};

}  // namespace b2style

#endif  // B2STYLE_LIB_B2STYLE_REF_H

```

而`vector`也更新了，不用再自己管理堆空间的分配和释放了，[service/compiler/b2style/lib/std/vector](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b2style/lib/std/vector)。

```cpp
#ifndef B2STYLE_LIB_STD_VECTOR
#define B2STYLE_LIB_STD_VECTOR

#include <b2style.h>
#include <assert.h>
#include <b2style/heap_ptr.h>
#include <std/types.h>

namespace std {

template <T>
class vector {
  ::b2style::heap_ptr<T> _a;
  int _s;

  int size() {
    return this._s;
  }

  int capacity() {
    return this._a.size();
  }

  T get(int index) {
    ::assert(index >= 0, "get");
    ::assert(index < this.size(), "get");
    return this._a.get(index);
  }

  void set(int index, T v) {
    ::assert(index >= 0, "set");
    ::assert(index < this.size(), "set");
    this._a.set(index, v);
  }

  void destruct() {
    this._a.destruct();
  }

  void reserve(int size) {
    ::b2style::heap_ptr<T> x(size);
    for (int i = 0; i < this.size(); i++) {
      x.set(i, this.get(i));
    }
	this.destruct();
    this._a = x;
	x.release();
  }

  void construct(int size) {
    this.reserve(size);
  }

  void construct() {
    this.construct(4);
  }

  void push_back(T v) {
    if (this.size() == this.capacity()) {
      this.reserve(this.capacity() << 1);
    }
    this._s++;
    this.set(this.size() - 1, v);
  }

  void pop_back() {
    ::assert(this.size() > 0, "pop_back");
    this._s--;
  }

  void clear() {
    this._s = 0;
  }
};

}  // namespace std

#endif  // B2STYLE_LIB_STD_VECTOR

```
