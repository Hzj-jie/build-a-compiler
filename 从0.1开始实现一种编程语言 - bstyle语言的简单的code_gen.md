# 从0.1开始实现一种编程语言 - bstyle语言的简单的code_gen

一些bstyle的code_gen相当简单，在这一起列出来。

logic：直接把后一项的字符串输出，当然，去掉前后的双引号。因为logic语言本身不使用引号，所以不需要处理\"的情况。[service/compiler/bstyle/logic/nodes/logic.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/bstyle/logic/nodes/logic.vb)

```vb.net
Public Function build(ByVal n As typed_node, ByVal o As writer) As Boolean Implements logic_gen.build
    o.append(n.child(1).word().str().Trim(character.quote))
    o.append(newline.incode())
    Return True
End Function

```

multi-sentence-paragraph：除了第一个“{”和最后一个“}”，其它的都是sentence，直接调用code_gens选择sentence的code_gen即可。[service/compiler/bstyle/logic/nodes/multi_sentence_paragraph.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/bstyle/logic/nodes/multi_sentence_paragraph.vb)

```vb.net
Public Function build(ByVal n As typed_node, ByVal o As writer) As Boolean Implements logic_gen.build
    Dim i As UInt32 = 1
    While i < n.child_count() - 1
        If Not l.of(n.child(i)).build(o) Then
            Return False
        End If
        i += uint32_1
    End While
    Return True
End Function

```

paragraph：更加简单，子节点是sentence或者multi-sentence-paragraph，直接调用code_gens选择code_gen即可。[service/compiler/bstyle/logic/nodes/paragraph.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/bstyle/logic/nodes/paragraph.vb)

```vb.net
Public Function build(ByVal n As typed_node, ByVal o As writer) As Boolean Implements logic_gen.build
    Return l.of(n.child()).build(o)
End Function

```

sentence，sentence-with-semi-colon，sentence-without-semi-colon：和paragraph一样，选择子节点的code_gen即可。[service/compiler/bstyle/logic/nodes/sentence.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/bstyle/logic/nodes/sentence.vb)

value-definition-with-semi-colon：忽略后面的“;”，只处理第一个子节点。[service/compiler/bstyle/logic/nodes/value_definition_with_semi_colon.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/bstyle/logic/nodes/value_definition_with_semi_colon.vb)

```vb.net
Public Function build(ByVal n As typed_node, ByVal o As writer) As Boolean Implements logic_gen.build
    Return l.of(n.child(0)).build(o)
End Function

```

value-with-bracket：忽略前后的“(”“)”，只处理中间一个子节点。[service/compiler/bstyle/logic/nodes/value_with_bracket.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/bstyle/logic/nodes/value_with_bracket.vb)

```vb.net
Public Function build(ByVal n As typed_node, ByVal o As writer) As Boolean Implements logic_gen.build
    Return l.of(n.child(1)).build(o)
End Function

```

value-with-comma：忽略后面的“,”，只处理第一个子节点。[service/compiler/bstyle/logic/nodes/value_with_comma.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/bstyle/logic/nodes/value_with_comma.vb)

```vb.net
Public Function build(ByVal n As typed_node, ByVal o As writer) As Boolean Implements logic_gen.build
    Return l.of(n.child(0)).build(o)
End Function

```

value-without-bracket：选择唯一的子节点的code_gen。[service/compiler/bstyle/logic/nodes/value_without_bracket.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/bstyle/logic/nodes/value_without_bracket.vb)

```vb.net
Public Function build(ByVal n As typed_node, ByVal o As writer) As Boolean Implements logic_gen.build
    Return l.of(n.child()).build(o)
End Function

```
