# 从0.1开始实现一种编程语言 - 用struct来实现class

[bstyle已经实现了struct](https://zhuanlan.zhihu.com/p/430741003)，[logic已经实现了参数引用](https://zhuanlan.zhihu.com/p/431336597)，b2style实现类就不再复杂了。从语言的用户来说，类是结构和其函数。从语言实现上来说，类还包括函数参数引用和重载。所以基本上来说如果一个语言支持结构体、函数参数引用和函数重载，那么就可以用这个语言实现一个支持类的语言。bstyle语言就满足上面的所有要求。

先看个例子，这也是一个测试样例，

[service/tests/compiler/b2style/codegen/class.txt](https://github.com/Hzj-jie/osi.net/blob/master/service/tests/compiler/b2style/codegen/class.txt)

```cpp
#include <b2style.h>

class C {
  int x;

  void add_x(int y) {
    this.x += y;
  }

  int with_x(int y) {
    return this.x + y;
  }

  int return_x() {
    return this.x;
  }
};

void main() {
  C c;
  c.add_x(100);
  b2style::std_out(c.with_x(100));
  b2style::std_out(c.return_x());
}

```

把这个class C用结构体和函数实现就是，

```cpp
#include <b2style.h>

struct C {
  int x;
};

void add_x(C& this, int y) {
  this.x += y;
}

int with_x(C& this, int y) {
  return this.x + y;
}

int return_x(C& this) {
  return this.x;
}

void main() {
  C c;
  add_x(c, 100);
  b2style::std_out(with_x(c, 100));
  b2style::std_out(return_x(c));
}

```

1. 先把class变成struct，只保留变量。
2. 把class的函数转换成普通的函数，添加一个引用参数this。
3. 把类的函数调用变成用struct的实例作为第一个参数的普通函数调用。

注意到因为函数重载已经被支持了，所以即便若干个类的函数重名，第一个参数this也可以保证调用到正确的函数。后面还会说到这些函数的命名空间也可以基于同样的规则而被忽略。

因为logic语言只实现了引用而没有指针，所以this不是指针，当然this是指针是不合理的。同时对类的任何调用都得前置一个this.。这可以在b2style的scope中添加变量，类似[bstyle/scope.variable](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/bstyle/scope.variable.vb)，不过这个不是很重要，就没有实现了。

添加词法和语法规则

```text
# service/compiler/b2sytle/codegen/nlexer_rule.txt
  kw-struct struct
+ kw-class class
  dot .
  name [\w,_,::][\w,\d,_,::,.]*

# service/compiler/b2style/codegen/syntaxer_rule.txt
- root-type [... typedef-with-semi-colon, struct, heap-declaration-with-semi-colon]
+ root-type [... typedef-with-semi-colon, struct, class, heap-declaration-with-semi-colon]
  # TODO: Support value-definition
  struct kw-struct name start-paragraph [value-declaration-with-semi-colon]* end-paragraph semi-colon
+ class kw-class name start-paragraph [value-declaration-with-semi-colon, function]* end-paragraph semi-colon

```

实现class的rewriter

class的rewriter把class的定义改写成一个结构体和若干个函数，对于类的每个子节点，要区分是函数还是变量定义。[osi.net/class.vb at master · Hzj-jie/osi.net](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b2style/rewriter/nodes/class.vb)

```vb.net
Public Function build(ByVal n As typed_node,
                      ByVal o As typed_node_writer) As Boolean Implements code_gen(Of typed_node_writer).build
    assert(Not n Is Nothing)
    assert(Not o Is Nothing)
    assert(n.child_count() >= 5)
    o.append("struct")
    Dim class_name As String = l.typed_code_gen(Of name)().name(n.child(1))
    o.append(class_name)
    o.append("{")
    ' Append variables into the structure.
    If Not streams.range(3, n.child_count() - uint32_2).
                   map(Function(ByVal i As Int32) As typed_node
                           Return n.child(CUInt(i))
                       End Function).
                   filter(AddressOf is_value_declaration).
                   map(Function(ByVal node As typed_node) As Boolean
                           Return l.of(node).build(o)
                       End Function).
                   aggregate(bool_stream.aggregators.all_true) Then
        Return False
    End If
    o.append("};")
    ' Append functions after the structure.
    If Not streams.range(3, n.child_count() - uint32_2).
                   map(Function(ByVal i As Int32) As typed_node
                           Return n.child(CUInt(i))
                       End Function).
                   filter(AddressOf is_function).
                   map(Function(ByVal node As typed_node) As Boolean
                           assert(Not node Is Nothing)
                           assert(node.child_count() = 5 OrElse node.child_count() = 6)
                           If Not l.of(node.child(0)).build(o) Then
                               Return False
                           End If
                           If Not l.of(node.child(1)).build(o) Then
                               Return False
                           End If
                           o.append("(").
                             append(class_name).
                             append("& this")
                           If node.child_count() = 6 Then
                               o.append(", ")
                               If Not l.of(node.child(3)).build(o) Then
                                   Return False
                               End If
                           End If
                           o.append(")")
                           If Not l.of(node.last_child()).build(o) Then
                               Return False
                           End If
                           Return True
                       End Function).
                   aggregate(bool_stream.aggregators.all_true) Then
        Return False
    End If
    Return True
End Function

```

修改function_call的rewriter

函数调用的时候也要特别处理类的实例调用函数的情况。[osi.net/function_call.vb at master · Hzj-jie/osi.net](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b2style/rewriter/nodes/function_call.vb)

```vb.net
If n.child(0).word().str().Contains(".") Then
    Dim dot_pos As Int32 = n.child(0).word().str().LastIndexOf(".")
    ' dot is not allowed to be the first character.
    assert(dot_pos > 0)
    ' This is not handled by nlexer_rule.
    If dot_pos = n.child(0).word().str().Length() - 1 Then
        raise_error(error_type.user, "Name is not allowed to be suffixed by dot.")
        Return False
    End If
    o.append(n.child(0).word().str().Substring(dot_pos + 1)).
      append("(").
      append(n.child(0).word().str().Substring(0, dot_pos))
    If n.child_count() = 4 Then
        o.append(", ")
        If Not l.of(n.child(2)).build(o) Then
            Return False
        End If
    End If
    o.append(")")
    Return True
End If

```

以上的修改基本在[osi.net/commit/f0ea5c8ec6a0b7c5c6da2f7faf10a9841c7c33a6](https://github.com/Hzj-jie/osi.net/commit/f0ea5c8ec6a0b7c5c6da2f7faf10a9841c7c33a6)中。

不过这样有个问题，b2style支持命名空间，所以任何一个在命名空间中的函数都会被命名为Namespace__Function。这和一般的类的实例的函数调用是不吻合的。比方说[service/tests/compiler/b2style/codegen/class_in_namespace.txt](https://github.com/Hzj-jie/osi.net/blob/master/service/tests/compiler/b2style/codegen/class_in_namespace.txt)

```cpp
#include <b2style.h>

namespace N {

class C {
  ::int x;

  ::void print() {
    ::b2style::std_out(this.x);
  }
};

C c;

::void print() {
  c.x = 2;
  c.print();
}

}  // namespace N

```

因为函数支持重载，而类的函数的第一个参数是类对应的结构体本身，所以这些函数都不需要被放置在同样的命名空间中。[osi.net/commit/da7f1e081574ac4d2be487266ec398838e0b10c1](https://github.com/Hzj-jie/osi.net/commit/da7f1e081574ac4d2be487266ec398838e0b10c1)

这样的实现支持一个c++中没有的功能。

```cpp
#include <b2style.h>

class C {
  int N::x;

  void N::print() {
    b2style::std_out(this.N::x);
  }
};

void main() {
  C c;
  c.N::x = 100;
  c.N::print();
  c.::N::x = 200;
  c.::N::print();
}

```
