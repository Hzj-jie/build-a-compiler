# 从0.1开始实现一个编程语言 - b3style中类的析构

[Zijie He：从0.1开始实现一个编程语言 - b3style的class](https://zhuanlan.zhihu.com/p/711767428)中提到，b2style只在`class-initializer`时生成析构函数的调用，而b3style也继承了这个漏洞。自然这是不对的，不过b2style实现中的这个漏洞并不是毫无原因的。简单说来b2style并没有特定的`value-declaration`和`value-definition`的实现，而是使用bstyle的实现。[service/compiler/b2style/b2style.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b2style/b2style.vb)

```vb.net
with(code_gen.of_all_children_with_precondition(Of typed_node_writer)(
         "value-definition",
         scope.variable_proxy.define(),
         scope.call_hierarchy_t.from_value_clause())).
with(code_gen.of_all_children_with_precondition(Of typed_node_writer)(
         scope.variable_proxy.define(), "value-declaration")).

```

b3style就需要自己来处理这两种语法，当然也有好处可以生成析构函数的调用。

- 这里并不是故意说的这么别扭，但是生成析构函数的调用是个比较准确的说法，析构函数的调用会在当前scope结束的时候被触发。

## value-declaration、value-definition和class-initializer

这是个有意思的话题，很多c++教程里面也会反复提及，一个类的对象有多种方式可以生成。

```cpp
C a;
C b(p1, p2);
C c{p1, p2};
C d = f(p1, p2);
C e = C(p1, p2);

```

其中b和c是一样的，只是c++11开始推荐使用{}调用构造函数而不是()，以避免语法冲突。e没什么特别的意义，但会让人疑惑这个语句是否会调用复制构造函数、移动构造函数或者赋值运算符。比如下面这个例子。

```cpp
#include <iostream>
using namespace std;

class C {
public:
  C(int x) {
    cout << "C(" << x << ")" << endl;
  }
  
  C(C&&) {
    cout << "C(C&&)" << endl;
  }
  
  C& operator=(const C&) {
    cout << "C& operator=(const C&)" << endl;
    return *this;
  }
  
  C& operator=(C&&) {
    cout << "C& operator=(C&&)" << endl;
    return *this;
  }
};

int main() {
    C b(1);
    C e = C(2);
    C f{3};
    f = C(4);

    return 0;
}

```

因为b3style并不实现所有的c++语法，所以这里只有abd三种情况，分别对应`value-declaration`、`class-initializer`和`value-definition`。

## value-declaration和class-initializer

这两个基本是一样的，差别只是调用的构造函数不同，前者只有`this`参数，后者则可能有别的参数。但下面两个语句生成的代码则是完全一样的。所以value-declaration这个名字变得不太准确了。

```cpp
class C { };
C c1;
C c2();

```

对于`class-initializer`，构造和析构函数都是一定会被调用的。但`value-declaration`就不太一样了，必须判断类型是否是类，如果是的话则和`class-initializer`一样调用构造和析构函数。而构造函数需要提供一个空的参数列表以区分`class-initializer`中的可能带有参数的列表。

[service/compiler/b3style/logic/nodes/value_declaration.vb@c59d63f](https://github.com/Hzj-jie/osi.net/blob/c59d63f4e438f0a7fd3ba9b90b52ad8e11458f31/service/compiler/b3style/logic/nodes/value_declaration.vb#L15)

```vb.net
            Dim type As String = n.child(0).input_without_ignored()
            Dim name As String = value_definition.name_of(n.child(1))
            If struct.define_in_stack(type, name, o) Then
                If scope.current().classes().is_defined(type) Then
                    ' No extra parameters to call the constructor.
                    value_list.with_empty()
                    Return class_initializer.construct_and_destruct(name, o)
                End If
                Return True
            End If
            Return declare_primitive_type(type, name, o)

```

而其中的`class_initializer.construct_and_destruct`则是简单的把之前的代码分离出来。

[service/compiler/b3style/logic/nodes/class_initializer.vb@c59d63f](https://github.com/Hzj-jie/osi.net/blob/c59d63f4e438f0a7fd3ba9b90b52ad8e11458f31/service/compiler/b3style/logic/nodes/class_initializer.vb#L17)

```vb.net
            If Not function_call.without_return(b2style.function_call.build_struct_function(
                                                    name,
                                                    scope.class_def.construct),
                                                o) Then
                Return False
            End If
            ' Functions are always in global namespace.
            ' Use of this function should only be in the !_disable_namespace.
            scope.current().when_end_scope(
                Sub()
                    value_list.with_empty()
                    assert(function_call.without_return(b2style.function_call.build_struct_function(
                                                            name,
                                                            scope.class_def.destruct),
                                                        o))
                End Sub)
            scope.current().
                  call_hierarchy().
                  to(scope.current_namespace_t.fully_qualified_name(scope.class_def.construct))
            scope.current().
                  call_hierarchy().
                  to(scope.current_namespace_t.fully_qualified_name(scope.class_def.destruct))
            Return True

```

调用构造函数，在当前scope结束时调用析构函数，标记构造和析构函数都被调用到，以防止被当成未使用的函数而删除。

## value-definition

和上面两个情况不同，`value-definition`不需要调用类的构造函数，而只是简单的复制右侧值，但仍要调用析构函数。所以得把`class-initializer.construct_and_destruct`拆分成`construct`和`destruct`，当然内容并没有什么太大的差别。[service/compiler/b3style/logic/nodes/class_initializer.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b3style/logic/nodes/class_initializer.vb)

```vb.net
        Public Shared Function construct(ByVal name As String, ByVal o As logic_writer) As Boolean
            assert(Not name.null_or_whitespace())
            assert(Not o Is Nothing)

            If Not function_call.without_return(b2style.function_call.build_struct_function(
                                                    name,
                                                    scope.class_def.construct),
                                                o) Then
                Return False
            End If
            scope.current().
                  call_hierarchy().
                  to(scope.current_namespace_t.fully_qualified_name(scope.class_def.construct))

            Return True
        End Function

        Public Shared Sub destruct(ByVal name As String, ByVal o As logic_writer)
            ' Functions are always in global namespace.
            ' Use of this function should only be in the !_disable_namespace.
            scope.current().when_end_scope(
                Sub()
                    value_list.with_empty()
                    assert(function_call.without_return(b2style.function_call.build_struct_function(
                                                            name,
                                                            scope.class_def.destruct),
                                                        o))
                End Sub)
            scope.current().
                  call_hierarchy().
                  to(scope.current_namespace_t.fully_qualified_name(scope.class_def.destruct))
        End Sub

```

`value-definition`调用`value-declaration`来完成申明部分，调用`value-clause`来完成赋值部分。[service/compiler/b3style/logic/nodes/value_definition.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b3style/logic/nodes/value_definition.vb)

```vb.net
             Return value_declaration.of(n, o) AndAlso
                    value_clause.stack_name_build(n.child(1), n.child(3), o)

```

所以需要改的其实还是`value-declaration`，简单来说就是在`value_declaration.of`中也生成析构函数的调用，`value-declaration`中有了两种类似的代码生成方式。上一种调用构造函数，后一个则没有。

```vb.net
        Private Function build(ByVal n As typed_node,
                               ByVal o As logic_writer) As Boolean Implements code_gen(Of logic_writer).build
            Return build(n,
                         Function(ByVal name As String) As Boolean
                             value_list.with_empty()
                             Return class_initializer.construct(name, o)
                         End Function,
                         o)
        End Function

        Public Shared Function [of](ByVal n As typed_node, ByVal o As logic_writer) As Boolean
            Return build(n,
                         Function(ByVal name As String) As Boolean
                             Return True
                         End Function,
                         o)
        End Function

```

这里公用的`build`函数基本是之前的函数，只是通过一个函数参数来生成构造函数的调用，如上在`value-definition`时，这个函数参数是空的。[service/compiler/b3style/logic/nodes/value_declaration.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b3style/logic/nodes/value_declaration.vb#L15)

```vb.net
        Private Shared Function build(ByVal n As typed_node,
                                      ByVal class_construct As Func(Of String, Boolean),
                                      ByVal o As logic_writer) As Boolean
            assert(Not n Is Nothing)
            assert(Not class_construct Is Nothing)
            assert(Not o Is Nothing)
            assert(n.child_count() >= 2)
            Dim type As String = n.child(0).input_without_ignored()
            Dim name As String = value_definition.name_of(n.child(1))
            If struct.define_in_stack(type, name, o) Then
                If scope.current().classes().is_defined(type) Then
                    If class_construct(name) Then
                        class_initializer.destruct(name, o)
                        Return True
                    End If
                    Return False
                End If
                Return True
            End If
            Return declare_primitive_type(type, name, o)
        End Function

```
