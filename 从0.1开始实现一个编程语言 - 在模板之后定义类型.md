# 从0.1开始实现一个编程语言 - 在模板之后定义类型

在[Zijie He：从0.1开始实现一种编程语言 - 简单的预展开模板](https://zhuanlan.zhihu.com/p/451620752)中提到模板展开的代码的位置总是在模板定义的位置，所以模板的类型参数必须在模板之后定义，不然编译时类型参数对应的类型不能被编译器理解。

比如这个例子

```cpp
#include <b2style.h>

class C {
  void print() {
    b2style::std_out("C");
  }
};

template <T>
class D {
  void print(T t) {
    t.print();
  }
};

template <T, T2>
class E {
  void print(T t, T2 t2) {
    t.print(t2);
  }
};

void main() {
  C c;
  D<C> d;
  E<D<C>, C> e;
  e.print(d, c);
}

```

会被编译成

```cpp
#include <b2style.h>

class C {
  void print() {
    b2style::std_out("C");
  }
};

class D_1_C {
  void print(C t) {
    t.print();
  }
};

class E_2_D_1_C_C {
  void print(D_1_C t, C t2) {
    t.print(t2);
  }
};

void main() {
  C c;
  D_1_C d;
  E_2_D_1_C_C e;
  e.print(d, c);
}

```

可见`C`必须在`D_1_C`之前，而这两个都必须在`E_2_D_1_C_C`之前。这个显然不太好，比如

```cpp
class C { int x; };
#include <vector>
void main() { std::vector<C> c; }

```

就是个莫名其妙的写法，一般都会把`#include <vector>`写在文件最前。 

这显然不是模板展开做法的限制，而只是在于在哪插入展开后的代码。比如说一个类的模板的展开可以插在一个允许类的代码的位置。b2style的语法相对简单，能允许模板插入生成代码的地方就是在`root-type`。[service/compiler/b2style/codegen/syntaxer_rule.txt#L4](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b2style/codegen/syntaxer_rule.txt#L4)

```text
root-type [base-root-type, namespace, class, template]

```

那么一个简单的想法就是模板在当前的`root-type`之前插入代码。模板代码不用再在输入中插入自己的代码嵌入器，而使用`root-type`提供的当前的嵌入器。

[osi.net/scope.template.vb at master · Hzj-jie/osi.net](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b2style/scope.template.vb#L106)

```vb.net
- If Not tbr.with_types(types).build(n, d.injector) Then
+ If Not tbr.with_types(paramtypelist).build(n, scope.current().root_type_injector().current()) Then

```

余下的代码主要在于怎么产生`scope.current().root_type_injector().current()`。大概分成两个部分，

1、[service/compiler/b2style/scope.root_type_injector.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b2style/scope.root_type_injector.vb)

和别的`scope`差不多，这是一个保存编译状态的结构。本身其实很简单，只是一个`typed_node_writer`，用于插入代码，`typed_node_writer`本身可以嵌套`typed_node_writer`。 

```vb.net
Partial Public NotInheritable Class b2style
    Partial Public NotInheritable Class scope
        ' Inject any code before the current root-type.
        Public NotInheritable Class root_type_injector_t
            Private i As typed_node_writer

            Public Sub _new(ByVal o As typed_node_writer)
                assert(Not o Is Nothing)
                i = New typed_node_writer()
                o.append(i)
            End Sub

            Public Function current() As typed_node_writer
                assert(Not i Is Nothing)
                Return i
            End Function
        End Class

        Public Function root_type_injector() As root_type_injector_t
            If is_root() Then
                assert(Not i Is Nothing)
                Return i
            End If
            assert(i Is Nothing)
            Return (+root).root_type_injector()
        End Function
    End Class
End Class

```

只在根`scope`上有这个类型的实例。

```vb.net
Private ReadOnly i As root_type_injector_t

<inject_constructor>
Public Sub New(ByVal parent As scope)
    MyBase.New(parent)
End Sub

Public Sub New()
    Me.New(Nothing)
    fc = New call_hierarchy_t()
    cn = New current_namespace_t()
    d = New define_t()
    i = New root_type_injector_t()
End Sub 

```

2、[osi.net/root_type.vb at master · Hzj-jie/osi.net](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b2style/rewriter/nodes/root_type.vb)

在处理`root-type`时调用`scope.current().root_type_injector()._new(o)`以生成新的`root_type_injector`。

```vb.net
Partial Public NotInheritable Class b2style
    Private NotInheritable Class root_type
        Implements code_gen(Of typed_node_writer)

        Private ReadOnly l As code_gens(Of typed_node_writer)

        <inject_constructor>
        Public Sub New(ByVal b As code_gens(Of typed_node_writer))
            assert(Not b Is Nothing)
            Me.l = b
        End Sub

        Public Function build(ByVal n As typed_node,
                              ByVal o As typed_node_writer) As Boolean Implements code_gen(Of typed_node_writer).build
            scope.current().root_type_injector()._new(o)
            Return l.of(n.child()).build(o)
        End Function
    End Class
End Class

```

主要的改动就是这些，[osi.net/commit/89bdef413b5521d582c2e2c7ecc0de6dde943d82](https://github.com/Hzj-jie/osi.net/commit/89bdef413b5521d582c2e2c7ecc0de6dde943d82)。

最后再加个测试，[service/tests/compiler/b2style/self-test/template_before_type.txt](https://github.com/Hzj-jie/osi.net/blob/master/service/tests/compiler/b2style/self-test/template_before_type.txt)

```cpp
#include <b2style.h>
#include <testing.h>
#include <std/vector>

class C {
  int x;
};

void main() {
  std::vector<C> v();
  for (int i = 0; i < 100; i++) {
    C c;
    c.x = i + 1;
    v.push_back(c);
  }

  for (int i = 0; i < 100; i++) {
    C c = v.get(i);
    b2style::testing::assert_equal<int>(c.x, i + 1);
  }
  b2style::testing::finished();
}

```

这里`class C`在`#include <std/vector>`之后，所以需要这个改动才能被编译。
