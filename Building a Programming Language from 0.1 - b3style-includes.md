# Building a Programming Language from 0.1 - b3style/includes

Although `b2style` is a superset of `bstyle`, in the current implementation their `include` statements are handled independently: `b2style` cannot include `bstyle` header files, and any file not found during `b2style` compilation is ignored and forwarded for `bstyle` to process later.

```vb.net
    ' TODO: Consider to include bstyle headers into b2style.
    Private NotInheritable Class include_with_string
        Inherits code_gens(Of typed_node_writer).include_with_string(Of scope.includes_t.proxy,
                                                                        includes.folders,
                                                                        includes.ignore_include_error)

        Protected Overrides Function file_parse(ByVal s As String, ByVal o As typed_node_writer) As Boolean
            Return includes.parse(s, o)
        End Function

        ' Forward missing files to the bstyle.
        Protected Overrides Function handle_not_dumpable(ByVal n As typed_node, ByVal o As typed_node_writer) As Boolean
            assert(Not n Is Nothing)
            assert(Not o Is Nothing)
            o.append(n)
            Return True
        End Function
    End Class 
```

The `TODO` here was never addressed.

Naturally, we do not want this issue to recur in `b3style`. The solution is simply to allow `b3style` to search for both `bstyle` and `b2style` header files as well. The main consideration is that built-in headers are extracted into a temporary directory the first time they are referenced, so `bstyle.includes` and `b2style.includes` need to be exposed for `b3style.includes` to use.

```vb.net
 Partial Public NotInheritable Class b3style
    Private Shared include_folders As argument(Of vector(Of String))

    Public MustInherit Class includes
        Inherits code_gens(Of logic_writer).includes(Of scope.includes_t.proxy,
                                                        folders,
                                                        ignore_include_error)

        Public Shared Shadows Function parse(ByVal i As String, ByVal j As logic_writer) As Boolean
            If i Is Nothing Then
                ' The file has been included already.
                Return True
            End If
            Return parse_wrapper.with_current_file(i, Function(ByVal s As String) As Boolean
                                                          Return code_builder.build(s, j)
                                                      End Function)
        End Function

        Public Structure folders
            Implements func_t(Of vector(Of String))

            Public Function run() As vector(Of String) Implements func_t(Of vector(Of String)).run
                Dim r As New vector(Of String)()

                Dim folder As String = Path.Combine(temp_folder, "b3style-inc")
                tar.gen.dump(b3style_lib.data, folder)
                r.emplace_back(folder)

                r.emplace_back(+b3style.include_folders)

                r.emplace_back(bstyle.includes.include_folders())
                r.emplace_back(b2style.includes.include_folders())
                Return r
            End Function
        End Structure
```

There is nothing else out of the ordinary—just reusing the existing `code_gens<WRITER>.includes`. The main changes are in [osi.net/commit/c5848e41539a6bd4e5da0c915635af8b77fdeb06](https://github.com/Hzj-jie/osi.net/commit/c5848e41539a6bd4e5da0c915635af8b77fdeb06).

Of course, the same design can also be applied to `b2style` so that `b2style` can directly include `bstyle` headers, allowing us to delete several ugly pieces of code. Although this may slightly reduce efficiency—since `b2style`'s code analysis is more complex than `bstyle`'s, and the code generated by `b2style` still has to be compiled again by `bstyle`. [osi.net/commit/72c18d060e10d094b5e532f04a8f6e3c3e587cd0](https://github.com/Hzj-jie/osi.net/commit/72c18d060e10d094b5e532f04a8f6e3c3e587cd0)
