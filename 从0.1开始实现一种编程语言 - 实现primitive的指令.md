# 从0.1开始实现一种编程语言 - 实现primitive的指令

一个指令包含两个功能无关的接口

1. 输入输出

同primitive处理器的输入输出定义，可以输入输出字符型或二进制的指令序列。

```text
Public Interface exportable
    Function export(ByRef b() As Byte) As Boolean
    Function import(ByVal i() As Byte, ByRef p As UInt32) As Boolean

    Function export(ByRef s As String) As Boolean
    Function import(ByVal s As vector(Of String), ByRef p As UInt32) As Boolean

    Function bytes_size() As UInt32
End Interface

```

2. 执行

操作虚拟层实现指令本身的功能。

```text
Public Interface instruction
    Inherits exportable

    Sub execute(ByVal imi As imitation)
End Interface

```

输入输出的接口可以简单的由指令的定义生成而不用重复手写代码。实现一个[commands-parser.cs](https://github.com/Hzj-jie/osi.net/blob/master/service/interpreter/primitive/codegen/commands-parser.cs)，这个程序输入指令集合的[commands.txt](https://github.com/Hzj-jie/osi.net/blob/master/service/interpreter/primitive/commands.txt)文件，输出以下文件

commands.enum

二进制指令的枚举，以保证每个指令序号的唯一性。

instructions

指令的输入输出实现。

instructions-exportable-test

指令输入输出实现的测试。

除此以外再实现每个指令的操作。[instructions.execute.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/interpreter/primitive/instructions.execute.vb)。

至此，整个primitive处理器就实现了，这个处理器已经可以进行支持的操作了。（[service/tests/interpreter/primitive/cases](https://github.com/Hzj-jie/osi.net/tree/master/service/tests/interpreter/primitive/cases)）
