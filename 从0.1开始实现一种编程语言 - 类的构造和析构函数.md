# 从0.1开始实现一种编程语言 - 类的构造和析构函数

开始之前，先看看c++中关于构造函数的怪异的语法，

```cpp
#include <iostream>

using namespace std;

class C {
 public:
  C() {
    cout << "C" << endl;
  }
};

int main()
{
    C c;  // 1
    C c2 = C();  // 2
    C c3{};  // 3
    C c4();  // 4
    c4();  // 5

    return 0;
}

C c4() {
  return C();
}

```

1，2，3都是调用默认构造函数的方法，其中2是很特别的，这个并没有同时调用`operator=`，具体可以再试试下面这个。

```cpp
#include <iostream>

using namespace std;

class C {
 public:
  C() { cout << "C" << endl; }
  C& operator = (const C& c) { cout << "operator=" << endl; return *this; }
};

int main()
{
    C c{};
    C c2 = C();
    C c3;
    c3 = C();

    return 0;
}

```

3是c++11开始的新语法，其还有些变体，比如`C a = {}`这种写法。4却不是构造函数，而是一个函数的forward declaration；5则调用了4的定义。

而第一个如果是使用默认`=default`构造函数，行为还不同，会变成`default-initialization`，所以这个代码在标准中的输出和预期的会有差别。

```cpp
#include <stdio.h>

int main()
{{
    int i = 100;
    printf("%d\n", i);
}{
    int i;
    printf("%d\n", i);
}{
    int i = int(0);
    printf("%d\n", i);
}
    return 0;
}

```

输出`100 100 0`其实也是符合标准的，比如在早期的borland turbo c++上。也有人说在某些编译参数上会有类似的行为。详见[C++ zero initialization - Why is `b` in this program uninitialized, but `a` is initialized?](https://stackoverflow.com/questions/54350114/c-zero-initialization-why-is-b-in-this-program-uninitialized-but-a-is-i)

当然还有更多更复杂的例子，比如引入pod之后情况会更多，不再细说，详见[Do the parentheses after the type name make a difference with new?](https://stackoverflow.com/questions/620137/do-the-parentheses-after-the-type-name-make-a-difference-with-new)。

是不是看起来头就很大，基本原因就是4不是调用构造函数，所以才有了2和3，而1则更多是和c兼容，c没有构造函数这么个东西。

还是先从构造和析构函数的定义开始吧，这两个函数其实并没有什么太特别的，只是两个在语言层面上会被自动调用的函数。前者在构造的时候被调用，后者在析构的时候被调用。而c++的`operator new`则把这个事情变得复杂了，其包含了分配内存和调用构造函数两个功能。`operator delete`类似，只是不提供额外的参数，因为析构函数没有参数。所以大概可以说，

```cpp
C* c = new C(100);

```

等同于，

```cpp
C* c = static_cast<C*>(malloc(sizeof(C)));
new (c) C(100);

```

第二个写法中的`(c)`称为placement，就是说在哪个位置调用`C::C(int)`构造函数，这是个语法上的要求，而不是原理上的。所以如果完全不用构造函数，而用类似`init`这样命名的函数，那这个例子就可以写成，

```text
C* c = new C();
c->init(100);
// 或者
C* c = static_cast<C*>(malloc(sizeof(C)));
c->init(100);

```

两者变成了一回事，析构函数也同样。

回到b2style现在的实现，无论是堆还是栈空间，分配都是自动的，没有`new`和`delete`运算符，也就是说在`value-declaration`的时候调用构造函数初始化即可，而在超出scope的时候调用析构函数即可。同时为了减少复杂度，在没有构造和析构函数的时候，要为这个类生成默认的构造和析构函数。

后一个相对简单，在[osi.net/class.vb at master · Hzj-jie/osi.net](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b2style/rewriter/nodes/class.vb)中。

```vb.net
Dim has_constructor As Boolean = False
Dim has_destructor As Boolean = False
streams.range(3, n.child_count() - uint32_2).
        map(class_body).
        filter(AddressOf is_function).
        foreach(Sub(ByVal node As typed_node)
                    assert(Not node Is Nothing)
                    assert(node.child_count() = 5 OrElse node.child_count() = 6)
                    ' No namespace is necessary, the first parameter contains namespace.
                    If node.child(1).input().Equals("construct") Then
                        has_constructor = True
                    ElseIf node.child(1).input().Equals("destruct") Then
                        has_destructor = True
                    End If
                    o.Append(node.child(0).input()).
                      Append(" ").
                      Append(_namespace.with_global_namespace(node.child(1).input())).
                      Append("(").
                      Append(class_name).
                      Append("& this")
                    ' With parameter list.
                    If node.child_count() = 6 Then
                        o.Append(", ").
                          Append(node.child(3).input())
                    End If
                    o.Append(")").
                      Append(node.last_child().input()).
                      AppendLine() ' beautiful output.
                End Sub)
If Not has_constructor Then
    o.Append("void construct(").Append(class_name).Append("& this){}")
End If
If Not has_destructor Then
    o.Append("void destruct(").Append(class_name).Append("& this){}")
End If

```

构造和析构函数本身是两个特殊命名的函数，`void construct(C& this, ...)`和`void destruct(C& this)`，因为~不是支持的函数名的字符，所以没用`~ClassName()`这种写法。同时明确了两个函数的返回值都是`void`，以减少不必要的新语法特征。

前一个则在新的语法`class-initializer`中。因为b2style并没有forward-declaration的概念，可以安全的使用`C c(parameters)`这样的语法。为了简化概念，`C c`则不调用构造函数和析构函数，`C c(parameters)`调用构造函数和析构函数。 

 语法规则的改动是

```text
class-initializer type-name name start-bracket [value-list]? end-bracket
b2style-sentence-with-semi-colon [..., class-initializer]? semi-colon

```

而`class_initializer`则很简单的把定义+构造函数变成两个bstyle的语句。[osi.net/class_initializer.vb at master · Hzj-jie/osi.net](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b2style/rewriter/nodes/class_initializer.vb)

```vb.net
Public Function build(ByVal n As typed_node,
                      ByVal o As typed_node_writer) As Boolean Implements code_gen(Of typed_node_writer).build
    assert(Not n Is Nothing)
    assert(Not o Is Nothing)
    assert(n.child_count() = 4 OrElse n.child_count() = 5)
    Dim class_name As String = n.child(0).input()
    If Not scope.current().classes().resolve(class_name) Then
        Return False
    End If
    If Not (o.append(n.child(0)) AndAlso
            o.append(n.child(1)) AndAlso
            o.append(";") AndAlso
            o.append("construct(") AndAlso
            o.append(n.child(1)) AndAlso
            If(n.child_count() = 5, o.append(",") AndAlso o.append(n.child(3)), True) AndAlso
            o.append(");")) Then
        Return False
    End If
    scope.current().when_end_scope(Sub()
                                       assert(o.append("destruct(") AndAlso
                                              o.append(n.child(1)) AndAlso
                                              o.append(");"))
                                   End Sub)
    scope.current().call_hierarchy().to("construct")
    scope.current().call_hierarchy().to("destruct")
    Return True
End Function

```

最后的`scope.current().when_end_scope`注册一个scope失效时的行为。

这样就差不多了，主要的改动都在[osi.net/commit/d19ea1c095b418ae59fe20a21f92041e349b0dd1](https://github.com/Hzj-jie/osi.net/commit/d19ea1c095b418ae59fe20a21f92041e349b0dd1)。

这个版本中，`class-initializer`只允许为类所用，不过这个限制其实并没有什么意义。所以在[Allow class-initializer to be used by non-class types · Hzj-jie/osi.net@0d9764c](https://github.com/Hzj-jie/osi.net/commit/0d9764cca935da68e225a736f7a0ac1e767a4af2)中这个限制被去掉了，直接写`void construct`和`void destruct`可以为非类的类型提供特殊的构造和析构函数。

```cpp
#include <b2style.h>
#include <testing.h>

void construct(int& this, int v) {
  this = v + 1;
}

void construct(int& this) {
  this.construct(1);
}

void destruct(int& this) {}

void main() {
  int x(100);
  int y();
  // TODO: Why b2style::testing::assert_equal<int>(x, 101) does not work?
  b2style::testing::assert_equal<int, int>(x, 101);
  b2style::testing::assert_equal<int, int>(y, 2);
  b2style::testing::finished();
} 

```

虽然这种行为似乎很特别而少见。
