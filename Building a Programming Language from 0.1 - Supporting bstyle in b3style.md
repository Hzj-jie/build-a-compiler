# Building a Programming Language from 0.1 - Supporting bstyle in b3style

Because `b3style` does not inherit from `bstyle`, `b3style` must use `b3style.scope` while also using `b2style`'s syntax. Consequently, `b3style` cannot directly use `bstyle`'s code, nor can it simply copy `bstyle`'s code verbatim.

Let's start with our goals. The first stage is to get `b3style` to pass all `bstyle` tests: [service/tests/compiler/b3style/b3style_bstyle_test.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/tests/compiler/b3style/b3style_bstyle_test.vb)

```vb.net
Option Explicit On
Option Infer Off
Option Strict On

Imports osi.root.template
Imports osi.root.utt
Imports osi.root.utt.attributes
Imports osi.service.automata
Imports osi.service.compiler
Imports osi.service.interpreter.primitive
Imports osi.service.resource

<test>
Public NotInheritable Class b3style_bstyle_test
    Inherits bstyle_test(Of PARSE)

    Public NotInheritable Class PARSE
        Inherits __do(Of console_io.test_wrapper, String, executor, Boolean)

        Public Overrides Function at(ByRef i As console_io.test_wrapper,
                                     ByRef j As String,
                                     ByRef k As executor) As Boolean
            Return b3style.with_functions(New interrupts(+i)).parse(j, k)
        End Function
    End Class

    <test>
    Private Shared Sub nlp_parsable()
        assertion.is_true(nlp.of_file(b3style.nlexer_rule, b3style.syntaxer_rule, Nothing))
    End Sub

    <test>
    Private Shared Sub real__file__()
        Dim io As New console_io.test_wrapper()
        Dim e As executor = Nothing
        Using b3style.parse_wrapper.with_current_file("real__file__.txt")
            assertion.is_true(b3style.with_functions(New interrupts(+io)).
                                      parse(_bstyle_test_data.real__file__.as_text(), e))
        End Using
        assertion.is_not_null(e)
        e.assert_execute_without_errors()
        assertion.equal(io.output(), "real__file__.txt")
    End Sub

    Private Sub New()
    End Sub
End Class
```

This test is very straightforward: it substitutes `b3style` for the compiler in `bstyle_test`, while keeping the input code and expected output identical to `bstyle`.

The second stage is to run `b2style`'s tests. As mentioned in the earlier article [Zijie He: Building a Programming Language from 0.1 - Purpose and Basic Implementation Structure of b2style](https://zhuanlan.zhihu.com/p/105230021), `b2style` compiles source code into `bstyle`, which is then compiled by `bstyle` into `logic` code. Since `b3style` is a superset of `bstyle`, once `b3style` fully implements `bstyle`'s functionality, `b2style` can use `b3style` to compile the generated `bstyle` code into `logic` code. Because a large portion of `bstyle` testing actually relies on `bstyle` code generated by `b2style`, doing this significantly increases test coverage.

For example, in [service/compiler/b2style/b2style.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b2style/b2style.vb):

```vb.net
    Public NotInheritable Shadows Class parse_wrapper_b3style
        Inherits rewriter_rule_wrapper(Of nlexer_rule_t,
                                          syntaxer_rule_t,
                                          __do.default_of(Of vector(Of Action(Of statements))),
                                          suffixes_t,
                                          rewriter_gens_t,
                                          scope).parse_wrapper

        Public Sub New(ByVal functions As interrupts)
            MyBase.New(functions)
        End Sub

        Protected Overrides Function text_import(ByVal s As String, ByVal o As exportable) As Boolean
            Return b3style.with_functions(functions).parse(s, o)
        End Function
    End Class
```

Any test that uses `b2style.parse_wrapper` can likewise be run with `b2style.parse_wrapper_b3style`. For example, [service/tests/compiler/b3style/b3style_b2style_b3style_self_test.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/tests/compiler/b3style/b3style_b2style_b3style_self_test.vb):

```vb.net
Option Explicit On
Option Infer Off
Option Strict On

Imports osi.root.connector
Imports osi.root.utt.attributes
Imports osi.service.compiler
Imports osi.service.interpreter.primitive

<test>
Public NotInheritable Class b3style_b2style_b3style_self_test
    Inherits b2style_self_test_runner

    Protected Overrides Function parse(ByVal functions As interrupts,
                                       ByVal content As String,
                                       ByRef e As executor) As Boolean
        Return New b2style.parse_wrapper_b3style(functions).parse(content, e)
    End Function

    Protected Overrides Function with_current_file(ByVal filename As String) As IDisposable
        Return b2style.parse_wrapper_b3style.with_current_file(filename)
    End Function

    Protected Overrides Function ignore_case(ByVal name As String) As Boolean
        assert(Not name.null_or_whitespace())
        Return name.Equals("struct-and-primitive-type-with-same-name.txt")
    End Function
End Class
```

Once both of these test suites pass, `b3style` will be essentially at parity with `bstyle`. As we will see shortly, they actually end up using the same underlying code.

First, let's look at how to get `b3style` to run a small subset of `bstyle_test`. As mentioned earlier, the code for supporting `bstyle` syntax in `b3style` is largely identical to `bstyle`; the main difference in most places is simply the `scope` type being used—or rather, changing nested classes of `bstyle` into nested classes of `b3style`.

- This stems from an earlier implementation detail where a lot of code called `scope.current()` to obtain the active `scope`. That was not a major issue in itself, aside from a slight performance overhead, because `bstyle` and `b2style` originally shared no common `scope` functions, making a base class or interface unsuitable. Even though we later introduced a base class so `b3style` could share functionality, we kept this thread-static access pattern.

So the first question is how to let `b3style` reuse `bstyle`'s code. The required change is actually trivial: replacing `Partial Public NotInheritable Class bstyle` with `Partial Public NotInheritable Class b3style`. Of course, we could use more elaborate design patterns to allow `b3style` to use `bstyle`'s code directly—for instance, decoupling the various `code_gen` implementations from `bstyle`, `b2style`, and `b3style`, similar to what we did for `scope`. However, that seems unnecessary when a simple `sed` replacement suffices.

Since built-in command-line text processing on Windows is rather weak, it is easier to write a very simple `sed` utility: [root/codegen/sed/sed.cs](https://github.com/Hzj-jie/osi.net/blob/master/root/codegen/sed/sed.cs).

```csharp
using System;
using System.IO;

public static class Program {
    public static void Main(string[] args) {
        if (args == null || (args.Length != 3 && args.Length != 2)) {
            Console.WriteLine("No strings to change or missing file name");
            Environment.Exit(1);
            return;
        }
        Action<String> w = a => {
            Console.Write(a);
            Console.Write('\n');
        };
        Action n = () => Console.Write('\n');

        n();
        w("'The following code is generated by /osi/root/codegen/sed/sed.exe");
        w("'by replacing");
        w("' " + args[0]);
        w("'into");
        w("' " + args[1]);
        w("'from the input file " + (args.Length == 2 ? "Console.In" : args[2]));
        w("'Do not edit it manually.");

        using (TextReader r = (args.Length == 2 ? Console.In : new StreamReader(args[2]))) {
            string l = null;
            while((l = r.ReadLine()) != null) {
                w(l.Replace(args[0], args[1]));
            }
        }
    }
}
```

This is a tiny 33-line program, more than half of which consists of comments and blank lines. All it does is perform line-by-line string replacement from an input file or standard input.

- In fact, this functionality is just a tiny subset of [root/codegen/precompile/precompile.cs](https://github.com/Hzj-jie/osi.net/blob/master/root/codegen/precompile/precompile.cs), but having a dedicated little utility for string replacement is very convenient.

In `b3style`, we use this tool to replace ` Class bstyle` with ` Class b3style`, allowing us to directly include the logic shared with `bstyle`. Just to run all of `bstyle`'s tests, 31 classes can be generated in this manner: [service/compiler/b3style/logic/nodes/from-bstyle.cmd](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b3style/logic/nodes/from-bstyle.cmd)

```bat
setlocal

path %PATH%;..\..\..\..\..\root\codegen\sed;

call :run raw_value
call :run biguint
call :run bool
call :run integer
call :run string
call :run ufloat

call :run logic_name
call :run function
call :run function_call
call :run ignore_result_function_call
call :run param
call :run return_clause
call :run value_clause
call :run value_declaration
call :run heap_declaration
call :run value_definition
call :run heap_name
call :run struct
call :run raw_variable_name
call :run value_list
call :run typedef
call :run static_cast
call :run multi_sentence_paragraph

call :run kw_func
call :run kw_line

```

Note that `raw_variable_name` does not exist in `b3style`'s syntax rules, but classes such as `heap_name` call its static helper functions. Therefore, it is registered using a special `without()` method—meaning it is included in the registration chain without actually registering a rule handler, simply to keep track of the reference: [service/compiler/code_gen/code_gens_registrar.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/code_gen/code_gens_registrar.vb)

```vb.net
Public Class code_gens_registrar(Of WRITER As New, RT As code_gens_registrar(Of WRITER, RT))
' ...

    ' Keep tracking of the code_gen without really using it.
    Public Function without(Of T As New)() As RT
        Return self()
    End Function
' ...
End Class
```

A few other node handlers are even simpler, performing only string manipulation without touching `scope` at all. Those can directly reuse `bstyle`'s classes:

Several others have virtually no custom logic and simply forward processing to all or some of their child nodes:

At this point, only the special `name` syntax remains. In `bstyle`, `name` is not handled directly, but rather through the `raw-variable-name` rule mentioned above. However, `raw-variable-name` does not exist in `b2style` and `b3style` syntax, so it requires special handling.

Since we only need to support `bstyle` functionality for now, the initial `b3style/name` implementation is very simple: [service/compiler/b3style/logic/nodes/name.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b3style/logic/nodes/name.vb)

```vb.net
 Option Explicit On
Option Infer On
Option Strict On

Imports osi.root.connector
Imports osi.root.formation
Imports osi.service.automata
Imports builders = osi.service.compiler.logic.builders

Partial Public NotInheritable Class b3style
    Private NotInheritable Class name
        Implements code_gen(Of logic_writer)

        Public Function build(ByVal n As typed_node,
                              ByVal o As logic_writer) As Boolean Implements code_gen(Of logic_writer).build
            ' TODO: This is a temporary solution to make bstyle work in b3style.
            assert(Not n Is Nothing)
            Return raw_variable_name.build(n,
                                           Function(ByVal type As String,
                                                    ByVal ps As stream(Of builders.parameter)) As Boolean
                                               scope.current().value_target().with_value(type, ps)
                                               Return True
                                           End Function,
                                           Function(ByVal type As String,
                                                    ByVal source As String) As Boolean
                                               scope.current().value_target().with_value(type, source)
                                               Return True
                                           End Function,
                                           o)
        End Function
    End Class
End Class
```

As you can see, this is the exact same logic as `bstyle/raw-variable-name`. Of course, we could also modify `bstyle` to handle `name` instead of `raw-variable-name`. However, given that `b2style/name` requires fairly complex functionality ([service/compiler/b2style/rewriter/nodes/name.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b2style/rewriter/nodes/name.vb)), `b3style/name` will inevitably need to be updated later anyway, so we can leave it like this for now.

Finally, all that remains are the prefix `code_types` and the suffixes `main` and `scope.call_hierarchy_t.calculator`. The first two can directly reuse `bstyle`'s implementations, while the third is already provided by `scope`.

Putting everything together gives us the compiler structure for `b3style`: [service/compiler/b3style/b3style.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b3style/b3style.vb)

```vb.net
Partial Public NotInheritable Class b3style
' ...

   Public NotInheritable Class suffixes_t
        Inherits __do(Of vector(Of Action(Of statements)))

        Protected Overrides Function at() As vector(Of Action(Of statements))
            Return vector.emplace_of(Of Action(Of statements))(AddressOf bstyle.code_types.register)
        End Function
    End Class

    Public NotInheritable Class suffixes_t
        Inherits __do(Of vector(Of Action(Of statements)))

        Protected Overrides Function at() As vector(Of Action(Of statements))
            Return vector.emplace_of(Of Action(Of statements))(AddressOf bstyle.main.register,
                                                               AddressOf scope.call_hierarchy_t.calculator.register)
        End Function
    End Class

    Public NotInheritable Class logic_gens_t
        Inherits __do(Of vector(Of Action(Of code_gens(Of logic_writer))))

        Protected Overrides Function at() As vector(Of Action(Of code_gens(Of logic_writer)))
            Return New code_gens_registrar(Of logic_writer)().
                with_of_only_childs(
                    "root-type",
                    "base-root-type",
                    "include",
                    "typedef-type",
                    "paragraph",
                    "sentence",
                    "sentence-with-semi-colon",
                    "value-without-bracket",
                    "base-value-without-bracket",
                    "variable-name",
                    "for-increase",
                    "base-for-increase"
                ).
                with(code_gen.of_ignore_last_child(Of logic_writer)("root-type-with-semi-colon")).
                with(Of include_with_file)().
                with(Of include_with_string)().
                with(Of biguint)().
                with(Of bool)().
                with(Of _integer)().
                with(Of _string)().
                with(Of ufloat)().
                with(Of bstyle.logic)().
                with(scope.define_t.code_gens.ifndef_wrapped(AddressOf code_gen_of)).
                with(scope.define_t.code_gens.define()).
                with(Of typedef)().
                with(Of bstyle.typedef_type_name)().
                with(Of bstyle.typedef_type_str)().
                with(Of heap_declaration)().
                with(Of heap_name)().
                with(Of struct)().
                with(Of value_declaration)().
                with(Of value_definition)().
                with(Of value_clause)().
                with(Of function_call)().
                with(Of return_clause)().
                with(Of static_cast)().
                with(Of ignore_result_function_call)().
                with(Of value_list)().
                without(Of raw_variable_name)().
                with(Of kw_file)().
                with(Of kw_func)().
                with(Of kw_line)().
                with(Of kw_statement)().
                with(Of _function)().
                with(Of param)().
                with(code_gen.of_all_children(Of logic_writer)("paramlist")).
                with(Of multi_sentence_paragraph)().
                with(code_gen.of_ignore_last_child(Of logic_writer)("base-sentence-with-semi-colon")).
                with(Of value)().
                with_of_all_childrens("raw-value").
                with(Of name)().
                with(code_gen.of_first_child(Of logic_writer)("param-with-comma")).
                with(code_gen.of_first_child(Of logic_writer)("value-with-comma")).
                with(Of condition)().
                with(code_gen.of_children(Of logic_writer)("else-condition", 1)).
                with(Of for_loop)().
                with(Of _delegate)()
        End Function
    End Class
End Class
```
