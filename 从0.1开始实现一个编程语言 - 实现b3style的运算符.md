# 从0.1开始实现一个编程语言 - 实现b3style的运算符

[Zijie He：从0.1开始实现一种编程语言 - b2style语言的目的和实现的基本结构](https://zhuanlan.zhihu.com/p/105230021)提到b2style和bstyle的两个重要的差别，命名空间和运算符。当然b2style还有比如类和模板的功能，不过和命名空间一样，运算符是值得优先实现的。

## function_call的支持

而和[Zijie He：从0.1开始实现一种编程语言 - 支持运算符](https://zhuanlan.zhihu.com/p/105513770)中所说的一样，b3style中的运算符也可以简单的使用函数来实现，不过不同之处在于b3style直接把代码编译为logic语句而不是bstyle语句。这个过程和实现`function_call`非常相似。差别在于`function_call`中通过第一个节点来获得函数名，第三个节点`paramlist`来获得`value_list`中的参数列表；而运算符则是由运算符本身转义为函数名，参数列表也由运算符两侧或一侧的值来提供。

```vb.net
' function_call对常规函数的处理
        Private Shared Function build(ByVal n As typed_node,
                                      ByVal o As logic_writer,
                                      ByVal build_caller As Func(Of String, vector(Of String), Boolean),
                                      ByVal build_caller_ref As Func(Of String, vector(Of String), Boolean)) As Boolean
            assert(Not n Is Nothing)
            assert(Not o Is Nothing)
            assert(n.child_count() >= 3)
            If n.child_count() = 3 Then
                value_list.with_empty()
            ElseIf Not code_gen_of(n.child(2)).build(o) Then
                Return False
            End If
            Return build(n.child(0).input_without_ignored(), build_caller, build_caller_ref)
        End Function

```

> 如上，当一个`function_call`只有三个节点时，即如`func()`时，`value_list`为空，没有参数。否则由`paramlist`产生`value_list`。

这里注意到`function_call`本身的主要逻辑其实并不很在意`value_list`从哪来，而只要求有一个`value_list`，这样可以简单的使用栈来完成函数调用的嵌套。所以其一个变种可以是，

```vb.net
        Public Shared Function build(ByVal function_name As String, ByVal o As logic_writer) As Boolean
            Return build(function_name, caller_builder(o), caller_ref_builder(o))
        End Function 

```

这里预期`value_list`由调用方处理。`function_call`的主要修改也就是增加这个重载，当然还有`without_return`的重载，其它则主要是工程上的小问题。改动后的`function_call`在[service/compiler/b3style/logic/nodes/function_call.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b3style/logic/nodes/function_call.vb)，而修改可见[commit/fffb736ec9b8ee94cfb1fb2d0ecb3aad17dc97fa#diff-88d4ffb9e3b8bbafa67a4e104e0bbc1789931d9629266978c756e3936d07e6b3](https://github.com/Hzj-jie/osi.net/commit/fffb736ec9b8ee94cfb1fb2d0ecb3aad17dc97fa#diff-88d4ffb9e3b8bbafa67a4e104e0bbc1789931d9629266978c756e3936d07e6b3)

## 调用运算符对应的函数

和b2style中的一样，运算符操作有两种，单计算数和双计算数。前者是比如`!boolean_value`，后者则是`number1+number2`。对应`unary_operation_value`和`binary_operation_value`。

[service/compiler/b3style/logic/nodes/binary_operation_value.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b3style/logic/nodes/binary_operation_value.vb)

```vb.net
    Private NotInheritable Class binary_operation_value
        Implements code_gen(Of logic_writer)

        Public Shared Function operation_function_name(ByVal op As String) As String
            assert(Not op.null_or_whitespace())
            Return scope.current_namespace_t.in_global_namespace(
                           scope.current_namespace_t.with_namespace("b2style", op.Replace("-"c, "_"c)))
        End Function

        Public Shared Function build(ByVal left As typed_node,
                                     ByVal op As String,
                                     ByVal right As typed_node,
                                     ByVal o As logic_writer) As Boolean
            assert(Not left Is Nothing)
            assert(Not op.null_or_whitespace())
            assert(Not right Is Nothing)
            assert(Not o Is Nothing)
            value_list.build(Sub(ByVal a As Action(Of typed_node))
                                 assert(Not a Is Nothing)
                                 a(left)
                                 a(right)
                             End Sub,
                             o)
            Return function_call.build(operation_function_name(op), o)
        End Function

        Private Function build(ByVal n As typed_node,
                               ByVal o As logic_writer) As Boolean Implements code_gen(Of logic_writer).build
            assert(Not n Is Nothing)
            assert(n.child_count() = 3)
            Return build(n.child(0), n.child(1).type_name, n.child(2), o)
        End Function

```

这是早版本的实现，不过调用方式更清晰一些。

和b2style一样，`operation_function_name`函数通过运算符的类型来查找对应的函数，比如`&&` / `and`对应的就是`bool and(bool i, bool j)`这个函数。

[service/compiler/b2style/lib/b2style/operators.h#L11](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b2style/lib/b2style/operators.h#L11)

```cpp
#ifndef B2STYLE_LIB_B2STYLE_OPERATORS_H
#define B2STYLE_LIB_B2STYLE_OPERATORS_H

#include <b2style/types.h>
#include <bstyle/int.h>
#include <bstyle/str.h>

namespace b2style {

bool and(bool i, bool j) {
  if (i) return j;
  return false;
}

// ...

```

而`build`函数则调用`value_list`产生参数列表，再调用前面提到的`function_call`的`build`函数生成logic语句。

同理`unary_operation_value`也是完全一样的，只是其只处理一个参数。[service/compiler/b3style/logic/nodes/unary_operation_value.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b3style/logic/nodes/unary_operation_value.vb)

```vb.net
        Private Function build(ByVal n As typed_node,
                               ByVal o As logic_writer) As Boolean Implements code_gen(Of logic_writer).build
            assert(Not n Is Nothing)
            assert(Not o Is Nothing)
            assert(n.child_count() = 2)
            Dim function_name As String =
                    binary_operation_value.operation_function_name(n.child(operator_index).type_name + suffix)
            value_list.build(Sub(ByVal a As Action(Of typed_node))
                                 assert(Not a Is Nothing)
                                 a(n.child(uint32_1 - operator_index))
                             End Sub,
                             o)
            Return function_call.build(function_name, o)
        End Function

```

## self_value_clause的一点差别

严格来说self_value_clause，也就是形如`i += 1;`这样的语句并不是一个值，而是一个赋值语句。不过其处理方式仍然可以和双计算数的运算符一样，即使用特定的使用引用的函数来实现。同样的做法其实在自增自减函数上已有实现。

[service/compiler/b2style/lib/b2style/operators.h#L299](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b2style/lib/b2style/operators.h#L299)

```cpp
biguint self_inc_post(biguint& x) {
  biguint r = x;
  logic "add b2style__x b2style__x @@prefixes@constants@int_1";
  return r;
}

// ...
#ifdef B3STYLE

void self_and(bool& i, bool j) {
  i = and(i, j);
}

```

不过即便在b2style的lib中，这段代码是b3style特有的。因为同样的逻辑其实在b2style/self_value_clause中实现过。[service/compiler/b2style/rewriter/nodes/self_value_clause.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b2style/rewriter/nodes/self_value_clause.vb)

```vb.net
    Private NotInheritable Class self_value_clause
        Implements code_gen(Of typed_node_writer)

        Private Const self_prefix As String = "self-"

        Private Function build(ByVal n As typed_node,
                               ByVal o As typed_node_writer) As Boolean Implements code_gen(Of typed_node_writer).build
            assert(n.child_count() = 3)
            If Not code_gen_of(n.child(0)).build(o) Then
                Return False
            End If
            Dim function_name As String = n.child(1).type_name
            assert(function_name.StartsWith(self_prefix))
            function_name = _namespace.bstyle_format.operator_function_name(
                                function_name.Substring(self_prefix.Length()))
            scope.current().call_hierarchy().to_bstyle_function(function_name)
            o.append("=")
            o.append(function_name)
            o.append("(")
            If Not code_gen_of(n.child(0)).build(o) Then
                Return False
            End If
            o.append(",")
            If Not code_gen_of(n.child(2)).build(o) Then
                Return False
            End If
            o.append(")")
            Return True
        End Function

```

当然b2style也可以改用完全一样的实现。

注意到这里的`self_and`本身返回类型是`void`，因为类似`i > (j += 1)`这种语法是不合法的，所以就用到`function_call.without_return`和其对应的`binary_operation_value.without_return`。

```vb.net
    Private NotInheritable Class function_call
    ' ...
        Public Shared Function without_return(ByVal function_name As String, ByVal o As logic_writer) As Boolean
            Return build(function_name, without_return_caller_builder(o), without_return_caller_ref_builder(o))
        End Function

    Private NotInheritable Class binary_operation_value
    ' ...
        Public Shared Function without_return(ByVal n As typed_node,
                                              ByVal o As logic_writer) As Boolean
            Return build(n, AddressOf function_call.without_return, o)
        End Function

    Private NotInheritable Class self_value_clause
    ' ...
        Private Function build(ByVal n As typed_node,
                               ByVal o As logic_writer) As Boolean Implements code_gen(Of logic_writer).build
            Return binary_operation_value.without_return(n, o)
        End Function

```

## 不一样的logic语句

在[Zijie He：从0.1开始实现一个编程语言 - 更完善的#ifndef](https://zhuanlan.zhihu.com/p/651984853)提到过`#ifdef B3STYLE`的用处，简单说来就是b2style处理命名空间过于简单，导致

```cpp
namespace b2style {
void f(int i) {}
}  // namespace b2style

```

会被非常简单的翻译成bstyle语句

```cpp
void b2style__f(b2style__int b2style__i) {}

```

在b2style中这并不是什么问题，不过如果使用logic语句，这里的变量名称就得使用bstyle的变量名。

而b3style对命名空间的处理要完善的多，并不会出现这种问题，所以logic语句中的变量名仍然是原变量名。这就需要b2style/operators.h中使用logic语句的函数为b3style提供一些特别的实现。

[service/compiler/b2style/lib/b2style/operators.h#L73C1-L85C7](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b2style/lib/b2style/operators.h#L73C1-L85C7)

```cpp
#ifdef B2STYLE
bool greater_than(biguint i, biguint j) {
  bool result;
  logic "more b2style__result b2style__i b2style__j";
  return result;
}
#else
bool greater_than(biguint i, biguint j) {
  bool result;
  logic "more result i j";
  return result;
}
#endif

```

而绝大多数不使用logic语句的函数并不需要这种变种。还有就是和标准的c++不同，`#ifdef`并不是预编译，所以其内部只能是`root-type`，比如一个函数，而不能只是一个语句。
