# 从0.1开始实现一个编程语言 - c/c++中常见的宏

c/c++提供了一系列所谓“标准预定义宏”[Standard Predefined Macros (The C Preprocessor)](https://gcc.gnu.org/onlinedocs/cpp/Standard-Predefined-Macros.html)，这些宏在编译期会被转换成所定义类型的值，比如`__FILE__`会被转换成代码所在文件的名字的字符串。 

这些宏的一个重要的作用是为日志之类的调试代码提供代码的位置信息。而因为这些宏在预编译期就已经被展开，所以不会如使用调试符号时（linux中的debug symbol，或者windows中的pdb文件）一样产生运行时的性能损失。

注意到bstyle和b2style至今还没有调试符号的概念，生成的primitive的指令基本上无法还原成原始的代码，在编写稍复杂的代码时调试成了一个很困难的问题，比如碰到`assert(false)`时甚至都不知道是哪里产生的。 当然也可以手动把这些内容都写进参数中，不过这样挺麻烦，所以考虑实现这么几个宏。

首先bstyle和b2style并没有颇为人诟病的宏的概念，代码都是在编译过程中一次转换的，所以实现这几个“宏”的并不是宏，而只是特定的词类型。

[service/compiler/shared/nlexer_rule.txt](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/shared/nlexer_rule.txt)

```text
kw-file __FILE__
kw-func __func__
kw-line __LINE__
kw-statement __STATEMENT__

```

这里实现四个“宏”，文件名、函数名、行数和当前语句。这四个“宏”可以作为普通的值。

[service/compiler/shared/syntaxer_rule.txt](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/shared/syntaxer_rule.txt)

```text
- base-value-without-bracket [..., string]
+ base-value-without-bracket [..., string, kw-file, kw-func, kw-line, kw-statement]

```

自然也会对应四个`code_gen`。 

[service/compiler/bstyle/bstyle.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/bstyle/bstyle.vb)

```vb.net
+     with(kw_file.instance).
+     with(kw_func.instance).
+     with(kw_line.instance).
+     with(kw_statement.instance)

```

[service/compiler/b2style/b2style.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b2style/b2style.vb)

```vb.net
+    with(kw_statement.instance).
+    with(code_gen.of_input(Of typed_node_writer)("kw-file")).
+    with(code_gen.of_input(Of typed_node_writer)("kw-func")).
+    with(code_gen.of_input(Of typed_node_writer)("kw-line")).

```

（在最开始的实现中，`kw-file`并不返回文件名，所以b2style不需要实现`kw-file`，而只需要直接转移给bstyle处理即可。） 

实现的原理是一样的，都是把这个值转成下一级语言支持的类型。这在b2style上相对简单，bstyle对这些类型支持很好，只需要简单的转换。比如，

```text
__FILE__  ->  "b2style/stdio.h"
__STATEMENT__  ->  "assert(__STATEMENT__, i > 0);"

```

而`__STATEMENT__`的实现则很简单，[service/compiler/b2style/rewriter/nodes/kw_statement.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b2style/rewriter/nodes/kw_statement.vb)

```vb.net
 Public Function build(ByVal n As typed_node,
                      ByVal o As typed_node_writer) As Boolean Implements code_gen(Of typed_node_writer).build
    assert(Not n Is Nothing)
    assert(Not o Is Nothing)
    Return assert(o.append("""" + n.ancestor_of("sentence").input().c_escape() + """"))
End Function

```

bstyle中相对复杂，因为要生成临时变量并使用`logic/copy_const`语句。简单的做法就是使用比如[service/compiler/bstyle/logic/nodes/integer.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/bstyle/logic/nodes/integer.vb)中的逻辑来生成代码。

```vb.net
Public Shared Function build(ByVal n As typed_node, ByVal i As Int32, ByVal o As logic_writer) As Boolean
    assert(Not n Is Nothing)
    assert(Not o Is Nothing)
    Return builders.of_copy_const(value.with_single_data_slot_temp_target(code_types.int, n, o),
                                  New data_block(i)).
                    to(o)
End Function

```

比如[service/compiler/bstyle/logic/nodes/kw_line.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/bstyle/logic/nodes/kw_line.vb)只需要调用这个函数即可。

```vb.net
Public Function build(ByVal n As typed_node,
                      ByVal o As logic_writer) As Boolean Implements code_gen(Of logic_writer).build
    Return _integer.build(n, CInt(n.char_start()), o)
End Function

```

而syntaxer中压根没有“行”这个概念，这里用的是字符的位置而不是行数。

剩下的则是怎么获得这些值本身了，稍微复杂一点的是[service/compiler/bstyle/logic/nodes/kw_statement.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/bstyle/logic/nodes/kw_statement.vb)，

```vb.net
public function build(byval n as typed_node,
                      byval o as logic_writer) as boolean implements code_gen(of logic_writer).build
    assert(not n is nothing)
    assert(not o is nothing)
    return _string.build(n, n.ancestor_of("sentence").input(), o)
end function

```

需要找到最近的一个`sentence`，并且输出代码的输入。

[service/automata/typed_node.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/automata/typed_node.vb)中新增的`ancestor_of`函数负责查找最近的一个父辈节点。

```vb.net
 Public Function ancestor_of(ByVal name As String, ByRef o As typed_node) As Boolean
    assert(Not name.null_or_empty())
    Dim n As typed_node = Me
    While True
        assert(Not n Is Nothing)
        If n.type_name.Equals(name) Then
            o = n
            Return True
        End If
        If n.root() Then
            Return False
        End If
        n = n.parent
    End While
    Return assert(False)
End Function

Public Function ancestor_of(ByVal name As String) As typed_node
    Dim o As typed_node = Nothing
    assert(ancestor_of(name, o))
    Return o
End Function

```

还有一个则是[service/compiler/bstyle/logic/nodes/kw_file.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/bstyle/logic/nodes/kw_file.vb)，因为需要支持`#include`，所以文件名则是由一个栈来维护。[osi.net/code_gen_rule_wrapper.vb at master · Hzj-jie/osi.net](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/code_gen/code_gen_rule_wrapper.vb)

```vb.net
 Public Shared Function current_file() As String
    Dim r As String = Nothing
    If instance_stack(Of String, parse_wrapper).back(r) Then
        Return r
    End If
    Return "unknown_file"
End Function

' @VisibleForTesting
Public Shared Function with_current_file(ByVal filename As String) As IDisposable
    assert(Not filename.empty_or_whitespace())
    instance_stack(Of String, parse_wrapper).current() = filename
    Return defer.to(Sub()
                        instance_stack(Of String, parse_wrapper).current() = Nothing
                    End Sub)
End Function

Public Function parse_file(ByVal filename As String, ByRef e As executor) As Boolean
    Dim o As executor = Nothing
    If Not with_current_file(filename, Function(ByVal s As String) As Boolean
                                           Return parse(s, o)
                                       End Function) Then
        Return False
    End If
    e = o
    Return True
End Function

```

同时[osi.net/includes.vb at master · Hzj-jie/osi.net](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/bstyle/logic/nodes/includes.vb)需要使用新的`with_current_file`函数来添加当前的文件名。

```vb.net
Public NotInheritable Class file_parser
    Inherits __do(Of String, logic_writer, Boolean)

    Public Overrides Function at(ByRef i As String, ByRef j As logic_writer) As Boolean
        If i Is Nothing Then
            ' The file has been included already.
            Return True
        End If
        Dim o As logic_writer = j
        Return parse_wrapper.with_current_file(i, Function(ByVal s As String) As Boolean
                                                      Return code_builder.current().build(s, o)
                                                  End Function)
    End Function
End Class

```

剩下的就是在比如[service/compiler/b2style/lib/assert.h](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b2style/lib/assert.h)中添加一个`string`类型的参数来使用`__STATEMENT__`，比如[service/tests/compiler/b2style/codegen/assert_with_statement.txt](https://github.com/Hzj-jie/osi.net/blob/master/service/tests/compiler/b2style/codegen/assert_with_statement.txt)。

```cpp
#include <b2style.h>
#include <assert.h>

void main() {
  int i = 100;
  assert(__STATEMENT__, i >= 100, "line 7");
  assert(__STATEMENT__, i < 100, "line 8");
}

```
