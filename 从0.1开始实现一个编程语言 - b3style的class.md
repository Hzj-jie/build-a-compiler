# 从0.1开始实现一个编程语言 - b3style的class

与b2style实现类的方式一样（[Zijie He：从0.1开始实现一种编程语言 - 用struct来实现class](https://zhuanlan.zhihu.com/p/437868234)），b3style也可以用结构体和函数来实现类。不记得有没有提到过，b2style中的函数都是在根命名空间，使用一个类型标记来判断不同的结构体。[service/compiler/scope/scope.struct.vb#L53](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/scope/scope.struct.vb#L53)

```vb.net
        Public Shared Function create_type_id(ByVal name As String) As builders.parameter
            assert(Not name.null_or_whitespace())
            Return builders.parameter.non_ref(name + "__struct__type__id__type", name + "__struct__type__id")
        End Function

        Public Function define(ByVal name As String,
                               ByVal members As vector(Of builders.parameter),
                               ByVal define_type As Action(Of String, UInt32)) As Boolean
            assert(Not name.null_or_whitespace())
            assert(Not members Is Nothing)  ' Allow empty struct
            assert(Not define_type Is Nothing)
            Dim full_type As String = builders.parameter_type.of(name).
                                               map_type(normalized_type.of).
                                               full_type()
            assert(Not builders.parameter_type.is_ref_type(full_type))
            Dim type_id As builders.parameter = create_type_id(name)
            define_type(type_id.map_type(normalized_type.of).non_ref_type(), uint32_1)
            members = members.CloneT().emplace_with(type_id)

```

其实这并不是必须的，特别是在b3style中，b3style可以自己记录类型。不过对于初始的实现，仿照b2style也不是什么坏事，更可以和重用bstyle代码一样重用b2style的代码。

回忆一下b2style中的实现，主要包含这么几个部分。1）把类转换成结构和函数，2）定义类的对象，3）调用类的对象的函数，4）调用类的构造和析构函数。

## 把类转换成结构和函数

这反倒是最简单的部分，因为可以重用b2style的代码，同样使用sed。[osi.net/service/compiler/b3style/logic/nodes/class.vb at master · Hzj-jie/osi.net](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b3style/logic/nodes/class.vb)

这里细节不再赘述。

## 定义类的对象

在b2style的实现中，这里是有个bug的。当一个语句是value-declaration时，b2style并不检查这个类型到底是类还是结构体，所以这样的类的对象并不会被析构。当然解决方法也很简单，之后再说。不过这里b3style也继承了这个bug。

所以这种情况下类的对象并不是由类的相关代码实现的，而是简单的由结构体的代码完成。[service/compiler/b3style/logic/nodes/value_declaration.vb#L34](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b3style/logic/nodes/value_declaration.vb#L34)

```vb.net
        Public Shared Function declare_struct_type(ByVal type As typed_node,
                                                   ByVal name As typed_node,
                                                   ByVal o As logic_writer) As Boolean
            assert(Not type Is Nothing)
            assert(Not name Is Nothing)
            Return struct.define_in_stack(type.input_without_ignored(), value_definition.name_of(name), o)
        End Function

```

## 调用类的对象的函数

这里开始有点不一样了，虽然大概的逻辑差不太多。b2style把对象的函数调用转译成bstyle的函数调用，但是b3style直接转换成logic语言的代码，同样也是b3style的function_call。

[osi.net/service/compiler/b3style/logic/nodes/function_call.vb at master · Hzj-jie/osi.net](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b3style/logic/nodes/function_call.vb)

```vb.net
                Dim struct_func As tuple(Of String, String) = Nothing
                If b2style.function_call.split_struct_function(raw_function_name, struct_func) Then
                    If Not raw_variable_name.build(struct_func.first(), o) Then
                        raise_error(error_type.user, "Cannot find class instance ", struct_func.first())
                        Return False
                    End If
                    parameters = (+scope.current().value_target().value()).names + parameters
                    function_name = scope.current_namespace_t.fully_qualified_name(struct_func.second())
                Else
                    function_name = _function.name_of(raw_function_name)
                End If

```

同样使用b2style的`function_call`的`split_struct_function`函数来判断一个函数调用是不是一个类的对象的函数，是的话则影响参数列表和函数名。之后使用常规的函数调用方式生成logic语言的代码。

```vb.net
                Dim name As String = Nothing
                If Not logic_name.of_function_call(function_name, parameters, name) Then
                    Return False
                End If

```

虽然并不会有这个中间输出，但实现上是将

```cpp
object.func(param1, param2);

```

转换成

```cpp
func(object, param1, param2);

```

而object本身则是类函数的this。

```cpp
func(C& this, P1 param1, P2 param2) { }

```

## 调用类的构造和析构函数

和b2style一样， b3style也有一个`class-initializer`语法，毕竟b3style使用的是b2style的语法定义。而`b3style/class_initializer`也和`b2style/class_initializer`一样包含定义类型、调用构造函数和调用析构函数三个部分。

[osi.net/service/compiler/b3style/logic/nodes/class_initializer.vb at master · Hzj-jie/osi.net](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b3style/logic/nodes/class_initializer.vb)

```vb.net
' 不大一样的地方是，b3style直接使用结构体的申明方式在当前的scope中定义类变量的所有的嵌套变量。
            If Not value_declaration.declare_struct_type(n.child(0), n.child(1), o) Then
                Return False
            End If
' 之后使用function_call调用构造函数本身。 
            If n.child_count() = 4 Then
                value_list.with_empty()
            ElseIf Not code_gen_of(n.child(3)).build(o) Then
                Return False
            End If
            If Not function_call.without_return(b2style.function_call.build_struct_function(
                                                    n.child(1).input_without_ignored(),
                                                    scope.class_def.construct),
                                                o) Then
                Return False
            End If
' 最后在当前scope结束时调用析构函数
            ' Functions are always in global namespace.
            ' Use of this function should only be in the !_disable_namespace.
            scope.current().when_end_scope(
                Sub()
                    value_list.with_empty()
                    assert(function_call.without_return(b2style.function_call.build_struct_function(
                                                            n.child(1).input_without_ignored(),
                                                            scope.class_def.destruct),
                                                        o))
                End Sub)

```

之后还有两句用以标记构造和析构函数都被调用，并需要被保留。[Zijie He：从0.1开始实现一种编程语言 - 优化一下，从编译结果中删除不需要的函数](https://zhuanlan.zhihu.com/p/443777931)

再剩下就是把b2style中关于类的测试在b3style下运行，还有些支撑以上功能的小改动。

但因为bstyle允许`f.f(1)`调用一个名为`f.f`的函数，而b2style和b3style都认为这是调用`f(f, 1)`，所以这个测试从b3style中移去。[osi.net/service/tests/compiler/bstyle/bstyle_test.vb at master · Hzj-jie/osi.net](https://github.com/Hzj-jie/osi.net/blob/master/service/tests/compiler/bstyle/bstyle_test.vb)
