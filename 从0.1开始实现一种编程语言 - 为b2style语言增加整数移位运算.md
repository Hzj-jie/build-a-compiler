# 从0.1开始实现一种编程语言 - 为b2style语言增加整数移位运算

移位运算相比浮点数运算要简单，只需要考虑primitive处理器的运算指令，词法和语法的规则文件和b2style的prefix中的函数就可以了。主要的差别在于类型本身已经可以正确处理了。

所以只需要一个改动就可以包含所有的内容，大量的代码都是生成的。[commit/93ec9158b7271028320e8f9f132757390dfad5fe](https://github.com/Hzj-jie/osi.net/commit/93ec9158b7271028320e8f9f132757390dfad5fe)

- 修改primitive的commands.txt文件，增加lfs和rfs两个指令。[commit/93ec9158b7271028320e8f9f132757390dfad5fe#diff-b24b8eea1107c7fec637fb01845ac62a](https://github.com/Hzj-jie/osi.net/commit/93ec9158b7271028320e8f9f132757390dfad5fe#diff-b24b8eea1107c7fec637fb01845ac62a)


- primitive指令的读写等的代码是自动生成的，而只需要实现指令执行的函数。[commit/93ec9158b7271028320e8f9f132757390dfad5fe#diff-f2e0c5ef5e140add4a8ed2159df2341e](https://github.com/Hzj-jie/osi.net/commit/93ec9158b7271028320e8f9f132757390dfad5fe#diff-f2e0c5ef5e140add4a8ed2159df2341e)

```vb.net
        Partial Public NotInheritable Class lfs
            Implements instruction

            Public Sub execute(ByVal imi As imitation) Implements instruction.execute
                assert(Not imi Is Nothing)
                Dim b1 As big_uint = Nothing
                Dim b2 As big_uint = Nothing
                b1 = New big_uint(+p1(imi))
                b2 = New big_uint(+p2(imi))
                p0(imi).set(b1.left_shift(b2).as_bytes())
            End Sub
        End Class

        Partial Public NotInheritable Class rfs
            Implements instruction

            Public Sub execute(ByVal imi As imitation) Implements instruction.execute

                Dim b2 As big_uint = Nothing

                b2 = New big_uint(+p2(imi))
                p0(imi).set(b1.right_shift(b2).as_bytes())
            End Sub
        End Class

```
