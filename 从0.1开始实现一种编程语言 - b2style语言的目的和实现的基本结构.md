# 从0.1开始实现一种编程语言 - b2style语言的目的和实现的基本结构

和bstyle语言相比，b2style语言提供了一些更加“平常”的功能，这里特指namespace和运算符。

b2style语言的输出是bstyle语言，之后再由bstyle语言的编译器编译。所以和bstyle语言不同，b2style语言使用之前提到的rewriter_rule_wrapper。b2style语言改写一些bstyle语言不支持的语法，而忽略绝大多数和bstyle一致的语法。

为了支持这些新增的功能，nlexer的规则文件需要一些不同的规则：[service/compiler/b2style/codegen/nlexer_rule.txt](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b2style/codegen/nlexer_rule.txt)

```text
less-or-equal <=
greater-or-equal >=
equal ==
less-than <
greater-than >

add \+
minus -
multiply \*
divide /
mod %
power ^
bit-and &
bit-or \|
and &&
or \|\|
not !
self-inc ++
self-dec --

kw-namespace namespace

name [\w,_,::][\w,\d,_,::]*
```

主要分成两类，前一半是各类运算符，后一半是对namespace的支持。

同理，syntaxer的规则也需要改变：[service/compiler/b2style/codegen/syntaxer_rule.txt](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b2style/codegen/syntaxer_rule.txt)

```text
ROOT_TYPES function, value-definition-with-semi-colon, namespace

namespace kw-namespace name start-paragraph [function, value-definition-with-semi-colon]* end-paragraph

value [value-with-bracket, value-without-bracket]
value-with-bracket start-bracket value end-bracket
raw-value [function-call, variable-name, integer, float, bool, string]
value-without-bracket [raw-value, value-with-operation]
value-with-operation [unary-operation-value, binary-operation-value]
unary-operation-value [pre-operation-value, post-operation-value]
pre-operation-value [not, self-inc, self-dec] value
# Should support post-operation-value value [self-inc, self-dec]
post-operation-value raw-value [self-inc, self-dec]
# Should support binary-operation-value value [add, minus, multiply, divide, mod, power, bit-and, bit-or, and, or, less-than, greater-than, less-or-equal, greater-or-equal, equal] value
binary-operation-value raw-value [add, minus, multiply, divide, mod, power, bit-and, bit-or, and, or, less-than, greater-than, less-or-equal, greater-or-equal, equal] value
```

同样也分成两类，前面是对namespace的支持，包括允许namespace为根类型。后一半是对value的改变，增加了运算符操作。

rewriter_rule_wrapper支持一种特殊的rewriter/code_gen，称为[rewriters.default](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/rewriter/default.vb)，在[rewriter_rule_wrapper.default_registerer](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/rewriter/rewriter_rule_wrapper.vb#L83)中引用。默认的typed_node的类型都由default_registerer直接将源代码输出而不做改写。[service/compiler/b2style/b2style.vb#L48](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b2style/b2style.vb#L48)

b2style支持运算符的方式是简单的将运算符转换为函数调用，比如

```text
a + b
```

转换为

```cpp
b2style::add(a, b)  // b2style支持namespace的形式
b2style__add(a, b)  // bstyle不支持namespace的形式

```

所以b2style需要一系列内置的函数。同时为了让b2style更加“可用”，再同时增加一些别的需要直接翻译为logic语言代码，或者说bstyle的logic语句，的函数。[service/compiler/b2style/rewriter/codegen/prefix.txt](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b2style/rewriter/codegen/prefix.txt)

引用其中的一些：

```cpp
string b2style__true_str = "True";
string b2style__false_str = "False";

void b2style__std_out(string i) {
  logic "interrupt stdout i @@prefixes@temps@string";
}

void b2style__std_err(string i) {
  logic "interrupt stderr i @@prefixes@temps@string";
}

void b2style__bool_std_out(bool i) {
  if (i) {
    b2style__std_out(b2style__true_str);
  } else {
    b2style__std_out(b2style__false_str);
  }
}

void b2style__bool_std_err(bool i) {
  if (i) {
    b2style__std_err(b2style__true_str);
  } else {
    b2style__std_err(b2style__false_str);
  }
}

void b2style__std_out(bool i) {
  b2style__bool_std_out(i);
}

void b2style__std_err(bool i) {
  b2style__bool_std_err(i);
}

int b2style__current_ms() {
  int result;
  logic "interrupt current_ms @@prefixes@temps@string result";
  return result;
}

```

其中的函数最终将相当的多，因为几乎所有的需要直接使用logic语句的函数都应该包含在其中。

b2style没有什么特殊的suffix。
