# 从0.1开始实现一个编程语言 - b3style_b2style_b3style_self_test

[Zijie He：从0.1开始实现一个编程语言 - 让b3style支持bstyle](https://zhuanlan.zhihu.com/p/639883836)中提到，可以用b3style替代bstyle用于给b2style将生成的bstyle的代码转换成logic语言，说起来很拗口。

回顾一下，b2style将代码编译为bstyle的代码，再由bstyle编译为logic的代码，最后再由logic编译为primitive的指令序列。因为b3style是bstyle的一个超集，即便没有完全实现b2style的语法，b3style也可以替代bstyle。

[service/compiler/b2style/b2style.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b2style/b2style.vb)

```vb.net
Partial Public NotInheritable Class b2style
' 使用bstyle编译b2style的输出
    Public NotInheritable Shadows Class parse_wrapper
        Inherits rewriter_rule_wrapper(Of nlexer_rule_t,
                                          syntaxer_rule_t,
                                          __do.default_of(Of vector(Of Action(Of statements))),
                                          suffixes_t,
                                          rewriter_gens_t,
                                          scope).parse_wrapper
        Public Sub New(ByVal functions As interrupts)
            MyBase.New(functions)
        End Sub
        Protected Overrides Function text_import(ByVal s As String, ByVal o As exportable) As Boolean
            Return bstyle.with_functions(functions).parse(s, o)
        End Function
    End Class

' 使用b3style编译b2style的输出
    Public NotInheritable Shadows Class parse_wrapper_b3style
        Inherits rewriter_rule_wrapper(Of nlexer_rule_t,
                                          syntaxer_rule_t,
                                          __do.default_of(Of vector(Of Action(Of statements))),
                                          suffixes_t,
                                          rewriter_gens_t,
                                          scope).parse_wrapper

        Public Sub New(ByVal functions As interrupts)
            MyBase.New(functions)
        End Sub

        Protected Overrides Function text_import(ByVal s As String, ByVal o As exportable) As Boolean
            Return b3style.with_functions(functions).parse(s, o)
        End Function
    End Class
End Class

```

理论上来说两个生成的primitive指令序列的执行结果应该一致，这是之前提到的弱等价。或者生成的logic语言的代码一致，这是强等价。介于当前b3style的子集的实现方式，两者应该是强等价。不过这不重要，实现b2style.parse_wrapper_b3style只是为了简单的提高b3style的测试覆盖率。

之后的事情相当简单，只要让所有b2style的测试通过一个模板函数参数，或者构造函数的函数参数来选择对应的parse_wrapper即可。比方说[service/tests/compiler/b2style/b2style_self_test.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/tests/compiler/b2style/b2style_self_test.vb)

```vb.net
<test>
Public NotInheritable Class b2style_self_test
    Inherits b2style_self_test_runner

    Protected Overrides Function parse(ByVal functions As interrupts,
                                       ByVal content As String,
                                       ByRef e As executor) As Boolean
        Return b2style.with_functions(functions).parse(content, e)
    End Function

    Protected Overrides Function with_current_file(ByVal filename As String) As IDisposable
        Return b2style.parse_wrapper.with_current_file(filename)
    End Function
End Class

```

和其对应的[service/tests/compiler/b3style/b3style_b2style_b3style_self_test.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/tests/compiler/b3style/b3style_b2style_b3style_self_test.vb)

```vb.net
<test>
Public NotInheritable Class b3style_b2style_b3style_self_test
    Inherits b2style_self_test_runner

    Protected Overrides Function parse(ByVal functions As interrupts,
                                       ByVal content As String,
                                       ByRef e As executor) As Boolean
        Return New b2style.parse_wrapper_b3style(functions).parse(content, e)
    End Function

    Protected Overrides Function with_current_file(ByVal filename As String) As IDisposable
        Return b2style.parse_wrapper_b3style.with_current_file(filename)
    End Function

    Protected Overrides Function ignore_case(ByVal name As String) As Boolean
        assert(Not name.null_or_whitespace())
        Return name.Equals("struct-and-primitive-type-with-same-name.txt")
    End Function
End Class

```

两者运行一样的测试，只是使用的编译方式不同。有些测试可能b3style无法实现，如这里看到的ignore_case函数，之后会再提到。

这几个测试自然一开始会失败，有几个语法没有实现。

```vb.net
                with(Of reinterpret_cast)().
                with(code_gen.of_ignore_last_child(Of logic_writer)("b2style-sentence-with-semi-colon")).
                with(Of dealloc)().
                with(Of undefine)().
                with(code_gen.of_children(Of logic_writer)("value-with-bracket", 1)).
                with(code_gen.of_input_without_ignored(Of logic_writer)("paramtype")).
                with_of_all_childrens("paramtypelist").
                with(code_gen.of_first_child(Of logic_writer)("paramtype-with-comma"))

```

reinterpret_cast，dealloc和undefine和其它的一样，由bstyle的代码通过sed替换生成，剩下的则是由子节点代理的语法。

最后就是这个测试[service/tests/compiler/b2style/self-test/struct-and-primitive-type-with-same-name.txt](https://github.com/Hzj-jie/osi.net/blob/master/service/tests/compiler/b2style/self-test/struct-and-primitive-type-with-same-name.txt)

```cpp
#include <b2style.h>
#include <testing.h>

typedef int INT;

struct INT {
  int x;
};

void main() {
  INT i;
  i.x = 100;
  b2style::testing::assert_equal<int>(i.x, 100);
  b2style::testing::finished();
}

```

这是个不标准的语法，[https://onlinegdb.com/UezoP9Dbl](https://onlinegdb.com/UezoP9Dbl)，不过之前bstyle可以支持这个语法。所以就暂时在b3style测试时忽略这个测试。

主要的代码在[commit/b8f09e3b157bc31f05eb9a9affebb47ebde8f432](https://github.com/Hzj-jie/osi.net/commit/b8f09e3b157bc31f05eb9a9affebb47ebde8f432)。
