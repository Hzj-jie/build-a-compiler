# Building a Programming Language from 0.1 - Defining Types After Templates

In [Zijie He: Building a Programming Language from 0.1 - Simple Pre-Expanded Templates](https://zhuanlan.zhihu.com/p/451620752), we noted that code generated by template expansion was always placed at the location of the template definition itself. Consequently, any type used as a template type argument could not be defined after the template (i.e., it had to be defined before the template); otherwise, the compiler would not recognize the type corresponding to the type parameter during compilation.

Take this example:

```cpp
#include <b2style.h>

class C {
  void print() {
    b2style::std_out("C");
  }
};

template <T>
class D {
  void print(T t) {
    t.print();
  }
};

template <T, T2>
class E {
  void print(T t, T2 t2) {
    t.print(t2);
  }
};

void main() {
  C c;
  D<C> d;
  E<D<C>, C> e;
  e.print(d, c);
}
```

This gets compiled into:

```cpp
#include <b2style.h>

class C {
  void print() {
    b2style::std_out("C");
  }
};

class D_1_C {
  void print(C t) {
    t.print();
  }
};

class E_2_D_1_C_C {
  void print(D_1_C t, C t2) {
    t.print(t2);
  }
};

void main() {
  C c;
  D_1_C d;
  E_2_D_1_C_C e;
  e.print(d, c);
}
```

As we can see, `C` must precede `D_1_C`, and both of them must precede `E_2_D_1_C_C`. This is obviously undesirable. For example:

```cpp
class C { int x; };
#include <vector>
void main() { std::vector<C> c; }
```

is a bizarre way to write code; normally, `#include <vector>` is placed at the very top of the file.

Clearly, this is not an inherent limitation of template expansion itself, but merely a question of where the expanded code is inserted. For instance, the expansion of a class template can be inserted at any location where a class definition is permitted. Because the grammar of b2style is relatively simple, the place where templates can insert generated code is at `root-type` ([service/compiler/b2style/codegen/syntaxer_rule.txt#L4](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b2style/codegen/syntaxer_rule.txt#L4)):

```text
root-type [base-root-type, namespace, class, template]
```

A simple idea, then, is for a template to insert its expanded code right before the current `root-type`. Instead of inserting its own code injector at the template definition site, the template uses the current injector provided by `root-type`.

[osi.net/scope.template.vb at master · Hzj-jie/osi.net](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b2style/scope.template.vb#L106)

```vb.net
- If Not tbr.with_types(types).build(n, d.injector) Then
+ If Not tbr.with_types(paramtypelist).build(n, scope.current().root_type_injector().current()) Then
```

The rest of the code mainly revolves around how `scope.current().root_type_injector().current()` is produced. It is roughly divided into two parts:

1. [service/compiler/b2style/scope.root_type_injector.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b2style/scope.root_type_injector.vb)

Like other components in `scope`, this is a structure that maintains compilation state. It is actually very simple—just a `typed_node_writer` used to insert code, taking advantage of the fact that a `typed_node_writer` can nest another `typed_node_writer` inside itself.

```vb.net
Partial Public NotInheritable Class b2style
    Partial Public NotInheritable Class scope
        ' Inject any code before the current root-type.
        Public NotInheritable Class root_type_injector_t
            Private i As typed_node_writer

            Public Sub _new(ByVal o As typed_node_writer)
                assert(Not o Is Nothing)
                i = New typed_node_writer()
                o.append(i)
            End Sub

            Public Function current() As typed_node_writer
                assert(Not i Is Nothing)
                Return i
            End Function
        End Class

        Public Function root_type_injector() As root_type_injector_t
            If is_root() Then
                assert(Not i Is Nothing)
                Return i
            End If
            assert(i Is Nothing)
            Return (+root).root_type_injector()
        End Function
    End Class
End Class
```

An instance of this type exists only on the root `scope`:

```vb.net
Private ReadOnly i As root_type_injector_t

<inject_constructor>
Public Sub New(ByVal parent As scope)
    MyBase.New(parent)
End Sub

Public Sub New()
    Me.New(Nothing)
    fc = New call_hierarchy_t()
    cn = New current_namespace_t()
    d = New define_t()
    i = New root_type_injector_t()
End Sub 
```

2. [osi.net/root_type.vb at master · Hzj-jie/osi.net](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b2style/rewriter/nodes/root_type.vb)

When processing a `root-type`, `scope.current().root_type_injector()._new(o)` is called to create a new `root_type_injector`:

```vb.net
Partial Public NotInheritable Class b2style
    Private NotInheritable Class root_type
        Implements code_gen(Of typed_node_writer)

        Private ReadOnly l As code_gens(Of typed_node_writer)

        <inject_constructor>
        Public Sub New(ByVal b As code_gens(Of typed_node_writer))
            assert(Not b Is Nothing)
            Me.l = b
        End Sub

        Public Function build(ByVal n As typed_node,
                              ByVal o As typed_node_writer) As Boolean Implements code_gen(Of typed_node_writer).build
            scope.current().root_type_injector()._new(o)
            Return l.of(n.child()).build(o)
        End Function
    End Class
End Class
```

Those are the main changes, which can be seen in [osi.net/commit/89bdef413b5521d582c2e2c7ecc0de6dde943d82](https://github.com/Hzj-jie/osi.net/commit/89bdef413b5521d582c2e2c7ecc0de6dde943d82).

Finally, let's add a test in [service/tests/compiler/b2style/self-test/template_before_type.txt](https://github.com/Hzj-jie/osi.net/blob/master/service/tests/compiler/b2style/self-test/template_before_type.txt):

```cpp
#include <b2style.h>
#include <testing.h>
#include <std/vector>

class C {
  int x;
};

void main() {
  std::vector<C> v();
  for (int i = 0; i < 100; i++) {
    C c;
    c.x = i + 1;
    v.push_back(c);
  }

  for (int i = 0; i < 100; i++) {
    C c = v.get(i);
    b2style::testing::assert_equal<int>(c.x, i + 1);
  }
  b2style::testing::finished();
}
```

Here, `class C` is defined after `#include <std/vector>`, so this change is required for it to compile.
