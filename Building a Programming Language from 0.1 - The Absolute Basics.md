# Building a Programming Language from 0.1 - The Absolute Basics

Human civilization is unlikely to be wiped out anytime soon, so there is really no reason to believe we need to build everything from raw binary code. That is why this series is called "Building a Programming Language from 0.1". Most of the content has no inherent tie to the host language and does not depend on any specific programming language. Simply out of habit, the implementation is written in [http://vb.net](http://vb.net).
