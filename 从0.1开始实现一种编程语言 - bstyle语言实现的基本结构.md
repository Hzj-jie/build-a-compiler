# 从0.1开始实现一种编程语言 - bstyle语言实现的基本结构

之前已经多多少少提到了bstyle语言的一些实现的细节，不过在这里还是合并起来。

首先设计的初衷是一个c语言的子集，除了内置logic的代码以外，其实现的代码可以用c语言的编译器编译。

这个子集相当的小，比如只支持函数调用，但是没有运算符，函数却支持重载。

这里存在两种不同类型的功能，一种与现有的功能存在“是”的关系。比如运算符“是”一种函数调用。namespace是另一个例子，虽然c语言中没有namespace，不过b2style中实现了namespace。namespace也只“是”一种特别的函数命名方式。

另一种则与现有的功能没有“是”的关系，比如函数重载需要logic语言本身的支持（之前提到的logic的宏的功能），但是b2style不直接生成logic语言的代码。所以如果bstyle语言不支持函数重载，则b2style支持函数重载则非常复杂。

所以bstyle语言使用nlexer和syntaxer进行词法和语法分析，用logic_rule_wrapper生成logic语言的代码，再用logic编译器编译成primitive的指令序列进行执行。

nlexer的规则文件：[service/compiler/bstyle/codegen/nlexer_rule.txt](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/bstyle/codegen/nlexer_rule.txt)

```text
kw-if if
kw-else else
kw-for for
kw-while while
kw-do do
kw-loop loop
kw-return return
kw-break break
kw-logic logic

blank [\b]+

bool [true,false]
integer [+,-]?[\d]+
float [+,-]?[\d]*.[\d]+
string "[\",*|"]*"

comma \,
colon :
question-mark ?
start-paragraph {
end-paragraph }
start-bracket (
end-bracket )
start-square-bracket \[
end-square-bracket \]
semi-colon ;

assignment =

name [\w,_][\w,\d,_]*

```

syntaxer的规则文件：[service/compiler/bstyle/codegen/syntaxer_rule.txt](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/bstyle/codegen/syntaxer_rule.txt)

```text
IGNORE_TYPES blank
ROOT_TYPES function, value-definition-with-semi-colon

function name name start-bracket [paramlist]? end-bracket multi-sentence-paragraph
paramlist [param-with-comma]* param
param-with-comma param comma
param name name

value-definition-with-semi-colon value-definition semi-colon

paragraph [sentence, multi-sentence-paragraph]
sentence [sentence-with-semi-colon, sentence-without-semi-colon]
sentence-with-semi-colon [value-definition, value-declaration, value-clause, return-clause, ignore-result-function-call, kw-break, logic]? semi-colon
sentence-without-semi-colon [condition, while, for-loop]

multi-sentence-paragraph start-paragraph [sentence]* end-paragraph

value-definition name name assignment value
value-declaration name name
value-clause name assignment value

condition kw-if start-bracket value end-bracket paragraph [else-condition]?
else-condition kw-else paragraph

while kw-while start-bracket value end-bracket paragraph

for-loop kw-for start-bracket [value-declaration, value-definition]? semi-colon [value]? semi-colon [value-clause]? end-bracket paragraph

value [value-with-bracket, value-without-bracket]
value-with-bracket start-bracket value end-bracket
value-without-bracket [function-call, variable-name, integer, float, bool, string]

variable-name name

ignore-result-function-call function-call

function-call name start-bracket [value-list]? end-bracket
value-list [value-with-comma]* value
value-with-comma value comma

return-clause kw-return [value]?
```

bstyle有三个prefixes：

内置的类型：[service/compiler/bstyle/logic/prefixes/types.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/bstyle/logic/prefixes/types.vb)

```text
bigint: type*
int: 4
long: 8
bool: 1
byte: 1
string: type*
float: 8
void: type0

```

常量：[service/compiler/bstyle/logic/prefixes/constants.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/bstyle/logic/prefixes/constants.vb)

```text
int_0, int_1, size_of_int, size_of_long, size_of_bool, size_of_byte, size_of_float

```

临时变量：[service/compiler/bstyle/logic/prefixes/temps.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/bstyle/logic/prefixes/temps.vb)

```text
bigint, string

```

常量和临时变量都不是必须的，只是用来减少不必要的重复。

bstyle有一个suffix，负责产生main函数的调用：[service/compiler/bstyle/logic/suffixes/main.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/bstyle/logic/suffixes/main.vb)

```text
caller main ( )

```
