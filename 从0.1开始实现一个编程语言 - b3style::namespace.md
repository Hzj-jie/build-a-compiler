# 从0.1开始实现一个编程语言 - b3style::namespace

作为一个更完善的b2style语言的实现，b3style支持b2style的所有语法，所以应该可以使用b2style语言的库。那么命名空间就是理所当然的除了bstyle语法以外的第一个需要实现的b2style语法的功能。

其实实现本身非常简单，基本的思路和b2style.scope._namespace一样。[service/compiler/b3style/logic/nodes/namespace.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b3style/logic/nodes/namespace.vb)

```vb.net
Partial Public NotInheritable Class b3style
    Private NotInheritable Class _namespace
        Implements code_gen(Of logic_writer)

        Private Function build(ByVal n As typed_node,
                               ByVal o As logic_writer) As Boolean Implements code_gen(Of logic_writer).build
            assert(Not n Is Nothing)
            assert(n.child_count() >= 4)
            Using scope.current().current_namespace().define(scope.current_namespace_t.of(n.child(1).word().str()))
                For i As UInt32 = 3 To n.child_count() - uint32_2
                    If Not code_gen_of(n.child(i)).build(o) Then
                        Return False
                    End If
                Next
            End Using
            Return True
        End Function
    End Class
End Class

```

简单来说就是让一个namespace中的所有语句都在对应的scope中，这样需要的时候就可以用`scope.current_namespace_t.of`把命名空间加在当前的名称之前。

不过和b2style中使用`_namespace.bstyle_format`不同，b3style直接把语句翻译成logic代码。因为命名空间的分隔符`::`在logic语法中是合法的，所以可以直接在其中使用完整的名称，类似于其它语言中的full-qualified name的概念。比方说b3style编译出的一个例子，

```text
callee ::to_long:BigUnsignedInteger long ( x BigUnsignedInteger ) { start_scope { define y long
 cut_len y x @@prefixes@constants@int_0 @@prefixes@constants@size_of_long
 return ::to_long:BigUnsignedInteger y } }

```

如此，b3style可以开始编译少量b2style的代码，之后就可以开始实现别的b2style的语句了。
