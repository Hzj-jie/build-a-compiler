# 从0.1开始实现一个编程语言 - 让b3style支持bstyle

因为b3style并不继承自bstyle，b3style需要使用b3style.scope，而同时b3style使用的是b2style的语法，所以首先b3style不能使用bstyle的代码，b3style也不能完全复制bstyle的代码。

还是先从目标开始，第一阶是让b3style可以运行所有的bstyle的测试。[service/tests/compiler/b3style/b3style_bstyle_test.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/tests/compiler/b3style/b3style_bstyle_test.vb)

```vb.net
Option Explicit On
Option Infer Off
Option Strict On

Imports osi.root.template
Imports osi.root.utt
Imports osi.root.utt.attributes
Imports osi.service.automata
Imports osi.service.compiler
Imports osi.service.interpreter.primitive
Imports osi.service.resource

<test>
Public NotInheritable Class b3style_bstyle_test
    Inherits bstyle_test(Of PARSE)

    Public NotInheritable Class PARSE
        Inherits __do(Of console_io.test_wrapper, String, executor, Boolean)

        Public Overrides Function at(ByRef i As console_io.test_wrapper,
                                     ByRef j As String,
                                     ByRef k As executor) As Boolean
            Return b3style.with_functions(New interrupts(+i)).parse(j, k)
        End Function
    End Class

    <test>
    Private Shared Sub nlp_parsable()
        assertion.is_true(nlp.of_file(b3style.nlexer_rule, b3style.syntaxer_rule, Nothing))
    End Sub

    <test>
    Private Shared Sub real__file__()
        Dim io As New console_io.test_wrapper()
        Dim e As executor = Nothing
        Using b3style.parse_wrapper.with_current_file("real__file__.txt")
            assertion.is_true(b3style.with_functions(New interrupts(+io)).
                                      parse(_bstyle_test_data.real__file__.as_text(), e))
        End Using
        assertion.is_not_null(e)
        e.assert_execute_without_errors()
        assertion.equal(io.output(), "real__file__.txt")
    End Sub

    Private Sub New()
    End Sub
End Class

```

这个测试非常简单，使用b3style替代bstyle_test中的编译器，而输入代码和输出都和bstyle一致。

第二阶则是使用b2style的测试，前文[Zijie He：从0.1开始实现一种编程语言 - b2style语言的目的和实现的基本结构](https://zhuanlan.zhihu.com/p/105230021)中提到b2style中代码是编译成bstyle，再由bstyle编译成logic代码。而b3style是bstyle的超集，如果b3style完全实现了bstyle的功能，b2style可以使用b3style将bstyle代码编译成logic代码。因为之前大量的bstyle测试其实依赖于b2style编译成的bstyle实现，如此实现可以极大提高测试覆盖率。

比方说，[service/compiler/b2style/b2style.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b2style/b2style.vb)

```vb.net
    Public NotInheritable Shadows Class parse_wrapper_b3style
        Inherits rewriter_rule_wrapper(Of nlexer_rule_t,
                                          syntaxer_rule_t,
                                          __do.default_of(Of vector(Of Action(Of statements))),
                                          suffixes_t,
                                          rewriter_gens_t,
                                          scope).parse_wrapper

        Public Sub New(ByVal functions As interrupts)
            MyBase.New(functions)
        End Sub

        Protected Overrides Function text_import(ByVal s As String, ByVal o As exportable) As Boolean
            Return b3style.with_functions(functions).parse(s, o)
        End Function
    End Class

```

而所有使用b2style.parse_wrapper的测试都可以同样用b2style.parser_wrapper_b3style运行。比如，[service/tests/compiler/b3style/b3style_b2style_b3style_self_test.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/tests/compiler/b3style/b3style_b2style_b3style_self_test.vb)

大约就是这两种测试都完成了以后，b3style就基本和bstyle一致了。后面会说到其实使用的代码是一样的。

还是先看怎么能用b3style运行一个很小的bstyle_test的集合。前面提到b3style支持bstyle语法的部分的代码有很大部分是相同的，很大部分的主要差别只在于使用的scope类型不同，或者说从bstyle的嵌套类变成b3style的嵌套类。

- 这是因为之前的一个实现的细节，大量的实现使用`scope.current()`来取得当前的scope。这本来没什么不得了的问题，除了性能上有些损失。毕竟bstyle和b2style的scope并没有什么公用的函数，基类或者接口都不合适。虽然后来为了能让b3style共享功能而实现了基类，但是并没有改变这个线程静态调用的设计。

所以首先考虑的是怎样让b3style使用bstyle的代码，需要的改动其实很简单，把`Partial Public NotInheritable Class bstyle`改成`Partial Public NotInheritable Class b3style`即可。当然也有别的方法可以使用更有趣的设计模式让b3style直接使用bstyle的代码，比如让各种`code_gen`的实现和bstyle，b2style或者b3style分离开，类似之前scope的改动。但这似乎并不很必要，因为可以简单的sed。 

Windows上基础命令行功能很薄弱，不如实现一个非常简单的sed。[root/codegen/sed/sed.cs](https://github.com/Hzj-jie/osi.net/blob/master/root/codegen/sed/sed.cs)。

```csharp
using System;
using System.IO;

public static class Program {
    public static void Main(string[] args) {
        if (args == null || (args.Length != 3 && args.Length != 2)) {
            Console.WriteLine("No strings to change or missing file name");
            Environment.Exit(1);
            return;
        }
        Action<String> w = a => {
            Console.Write(a);
            Console.Write('\n');
        };
        Action n = () => Console.Write('\n');

        n();
        w("'The following code is generated by /osi/root/codegen/sed/sed.exe");
        w("'by replacing");
        w("' " + args[0]);
        w("'into");
        w("' " + args[1]);
        w("'from the input file " + (args.Length == 2 ? "Console.In" : args[2]));
        w("'Do not edit it manually.");

        using (TextReader r = (args.Length == 2 ? Console.In : new StreamReader(args[2]))) {
            string l = null;
            while((l = r.ReadLine()) != null) {
                w(l.Replace(args[0], args[1]));
            }
        }
    }
}

```

这是一个只有33行的非常简单的程序，其中还有大半是注释和空行。只能把输入文件或者命令行输入以行为单位进行字符串替换。

- 其实这个功能不过是[root/codegen/precompile/precompile.cs](https://github.com/Hzj-jie/osi.net/blob/master/root/codegen/precompile/precompile.cs)的一个很小的子集，不过用这个小程序实现字符串替换其实很方便。

在b3style中使用这个程序把` Class bstyle`换成` Class b3style`，然后即可直接在b3style中包含和bstyle重复的逻辑。如果只需要运行所有bstyle的测试，那么有31个类可以通过这种方式实现。[service/compiler/b3style/logic/nodes/from-bstyle.cmd](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b3style/logic/nodes/from-bstyle.cmd)

```bat
setlocal

path %PATH%;..\..\..\..\..\root\codegen\sed;

call :run raw_value
call :run biguint
call :run bool
call :run integer
call :run string
call :run ufloat

call :run logic_name
call :run function

call :run ignore_result_function_call

call :run value_clause
call :run value_declaration

call :run heap_name

```

注意到`raw_variable_name`在b3style的语法中并没有，但是比如`heap_name`会使用到其中的静态函数，所以用了个很特别的`without()`方式注册，即包含在注册语句中但并不真的注册，只是方便记录其引用。[service/compiler/code_gen/code_gens_registrar.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/code_gen/code_gens_registrar.vb)

```vb.net
Public Class code_gens_registrar(Of WRITER As New, RT As code_gens_registrar(Of WRITER, RT))
' ...

    ' Keep tracking of the code_gen without really using it.
    Public Function without(Of T As New)() As RT
        Return self()
    End Function
' ...
End Class
```

至此为止，只剩下最特殊的`name`语法了。其在bstyle中并不直接被处理，而是通过上面提到的`raw-variable-name`语法来处理。 但`raw-variable-name`在b2style和b3style的语法中并不存在，所以需要特殊处理。

因为暂时只支持bstyle的功能，所以初始的b3style/name非常简单。[service/compiler/b3style/logic/nodes/name.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b3style/logic/nodes/name.vb)

```vb.net
 Option Explicit On
Option Infer On
Option Strict On

Imports osi.root.connector
Imports osi.root.formation
Imports osi.service.automata
Imports builders = osi.service.compiler.logic.builders

Partial Public NotInheritable Class b3style
    Private NotInheritable Class name
        Implements code_gen(Of logic_writer)

        Public Function build(ByVal n As typed_node,
                              ByVal o As logic_writer) As Boolean Implements code_gen(Of logic_writer).build
            ' TODO: This is a temporary solution to make bstyle work in b3style.
            assert(Not n Is Nothing)
            Return raw_variable_name.build(n,
                                           Function(ByVal type As String,
                                                    ByVal ps As stream(Of builders.parameter)) As Boolean
                                               scope.current().value_target().with_value(type, ps)
                                               Return True
                                           End Function,
                                           Function(ByVal type As String,
                                                    ByVal source As String) As Boolean
                                               scope.current().value_target().with_value(type, source)
                                               Return True
                                           End Function,
                                           o)
        End Function
    End Class
End Class

```

可以看出这就是bstyle/raw-variable-name的逻辑。当然也可以修改bstyle，让其不处理`raw-variable-name`，转而处理`name`。不过介于b2style/name需要的功能相当复杂，[service/compiler/b2style/rewriter/nodes/name.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b2style/rewriter/nodes/name.vb)，之后总归需要修改b3style/name的实现，所以暂时就保持如此。

最后剩下的就是前缀`code_types和后缀main`和`scope.call_hierarchy_t.calculator`。前两者可以直接使用bstyle的实现，后者是scope中的功能。

综合以上，就得到了b3style的编译器结构[service/compiler/b3style/b3style.vb](https://github.com/Hzj-jie/osi.net/blob/master/service/compiler/b3style/b3style.vb)

```vb.net
Partial Public NotInheritable Class b3style
' ...

   Public NotInheritable Class suffixes_t
        Inherits __do(Of vector(Of Action(Of statements)))

        Protected Overrides Function at() As vector(Of Action(Of statements))
            Return vector.emplace_of(Of Action(Of statements))(AddressOf bstyle.code_types.register)
        End Function
    End Class

    Public NotInheritable Class suffixes_t
        Inherits __do(Of vector(Of Action(Of statements)))

        Protected Overrides Function at() As vector(Of Action(Of statements))
            Return vector.emplace_of(Of Action(Of statements))(AddressOf bstyle.main.register,
                                                               AddressOf scope.call_hierarchy_t.calculator.register)
        End Function
    End Class

    Public NotInheritable Class logic_gens_t
        Inherits __do(Of vector(Of Action(Of code_gens(Of logic_writer))))

        Protected Overrides Function at() As vector(Of Action(Of code_gens(Of logic_writer)))
            Return New code_gens_registrar(Of logic_writer)().
                with_of_only_childs(
                    "root-type",
                    "base-root-type",
                    "include",
                    "typedef-type",
                    "paragraph",
                    "sentence",
                    "sentence-with-semi-colon",
                    "value-without-bracket",
                    "base-value-without-bracket",
                    "variable-name",
                    "for-increase",
                    "base-for-increase"
                ).
                with(code_gen.of_ignore_last_child(Of logic_writer)("root-type-with-semi-colon")).
                with(Of include_with_file)().
                with(Of include_with_string)().
                with(Of biguint)().
                with(Of bool)().
                with(Of _integer)().
                with(Of _string)().
                with(Of ufloat)().
                with(Of bstyle.logic)().
                with(scope.define_t.code_gens.ifndef_wrapped(AddressOf code_gen_of)).
                with(scope.define_t.code_gens.define()).
                with(Of typedef)().
                with(Of bstyle.typedef_type_name)().
                with(Of bstyle.typedef_type_str)().
                with(Of heap_declaration)().
                with(Of heap_name)().
                with(Of struct)().
                with(Of value_declaration)().
                with(Of value_definition)().
                with(Of value_clause)().
                with(Of function_call)().
                with(Of return_clause)().
                with(Of static_cast)().
                with(Of ignore_result_function_call)().
                with(Of value_list)().
                without(Of raw_variable_name)().
                with(Of kw_file)().
                with(Of kw_func)().
                with(Of kw_line)().
                with(Of kw_statement)().
                with(Of _function)().
                with(Of param)().
                with(code_gen.of_all_children(Of logic_writer)("paramlist")).
                with(Of multi_sentence_paragraph)().
                with(code_gen.of_ignore_last_child(Of logic_writer)("base-sentence-with-semi-colon")).
                with(Of value)().
                with_of_all_childrens("raw-value").
                with(Of name)().
                with(code_gen.of_first_child(Of logic_writer)("param-with-comma")).
                with(code_gen.of_first_child(Of logic_writer)("value-with-comma")).
                with(Of condition)().
                with(code_gen.of_children(Of logic_writer)("else-condition", 1)).
                with(Of for_loop)().
                with(Of _delegate)()
        End Function
    End Class
End Class
```
